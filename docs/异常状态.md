# 异常状态

## 着火

标识burn。每秒造成3点伤害，持续4秒，每0.5秒结算1.5点；重复命中刷新持续时间、不叠加伤害，且不推迟已排定的下一跳。按玩家时间结算，狂暴的环境减速不会放慢自身燃烧。

格挡成功且无生命伤害时不附着；晚格挡产生穿透伤害、破防或直接命中均可附着。伤害受生命减伤影响，护盾优先吸收；大笑期间伤害减半。持续伤害不造成冲击、不扣绷住、不触发金光，不会被受击无敌帧阻止。会打断喝药，但不反复打断玩家攻击或蓄力。

一次前滚开始时扑灭；后空翻和侧闪不能灭火。状态栏显示火焰图标与倒计时，身上有火焰提示；死亡、战斗结束、重置清除。

由通用StatusEffects保存刷新与定时结算数据，招式通过statusOnHit配置施加，不按敌人名称特判。
