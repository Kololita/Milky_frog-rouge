# 远征地图

## 层数与节点

在主菜单打开「开始新游戏」，可随机开局，或先选择「自定义游戏」并输入恰好 9 位数字。前导零会保留。

每次进房间自动写入本地存档。设置里的「保存并退出」会保留已结算的房间和当前装备。战斗中退出会重回本场战前准备，生命和血瓶恢复到进场时的数值。主菜单可继续这局远征，或确认放弃后再开新局。

每局 16 层。边只通向下一层，所有路线最终到达第 16 层唯一的首领武士。第 15 层全是休息处，每个首领入口都来自休息处。每层最多 6 个节点，每个节点最多有 3 条入边、3 条出边。第一层固定为普通战斗，前四层不出现精英，前三层不出现休息处或商店。精英、休息处和商店各自不会直接连到同类节点。

全图以 **2∶2∶1∶4∶5** 为精英、休息处、商店、事件、普通战斗的目标比例。每张地图随机分配 6～10 个精英和 5～8 个普通休息处，另有三个固定的关底休息处。关底休息处计入比例，首领单独计算。生成器根据精英与休息处的合计数量分配商店、事件和普通战斗，并在满足楼层及相邻限制的前提下打散节点位置。地图仅显示节点类型，不公开敌方阵容。

每对相邻楼层按节点从左到右的顺序连线，路线可以合流或分叉，边只会在共同端点相交。普通楼层允许单出口，生成时会降低连续多层只有一个出口的路线出现概率。最后三条路线经各自的关底休息处汇入首领。

绘制时错开同层节点的高度，并微调坐标，让相邻路线围成的各个区域面积尽量与其边数减二成正比。任意两个节点的中心距离至少为 150 个地图像素，约等于图上 15 段虚线加间隔的长度。窄屏可横向滚动查看整张地图。调整坐标时保持连线无交叉，逻辑楼层与可走路线保持原样。

## 金币与商店

战斗获胜时每只小怪给 10–20 金币，每只精英给 30–50 金币，端点均可抽到。结算画面显示本次战斗的掉落金额。远行盘缠提供的 70 金币计入开局余额。商店各品质价格为 24、38、58、82、110 金币。

点击房间后，地图立刻将该房间标为当前位置。打开商店内的「查看地图」可以直接选择相连的下一间房，选择后离开当前商店。

## 弱／强阵容池

“弱怪”和“强怪”是遭遇阵容的分类，不是怪物属性。同名怪物无论位于哪个阵容，生命、攻击力与招式一致，没有隐含增幅。

按本局实际进入的普通战斗计数：前两场使用弱池，从第三场起使用强池。精英与休息处不计入；配装取消不计入，重复打开同一节点不重抽阵容。阵容由地图种子、节点和计数决定，同一种子与同一路线可以复现；连续普通战斗尽量避开同一阵容。

首场精英战在全体精英中等概率抽取。后续每场排除上一次遇到的精英，再从其余精英中等概率抽取。中间经过其他房间不会清除这一记录。抽选由地图种子和本局路线决定。

- 弱池：拳兵、刺壳虫、灯笼灵单独出场。
- 强池：镜盾侍单独出场，或下列双怪组合。

| 双怪组合 | 特色 |
| --- | --- |
| 灯笼灵＋刺壳虫 | 增幅与远程灯火掩护低位冲锋、近身环刺 |
| 拳兵＋灯笼灵 | 拳兵近身，灯笼提供增幅、震波与远程追光 |
| 弩尾蜥＋刺壳虫 | 独立后撤、晶矢三射配合正面冲锋，高低判定交错 |
| 弩尾蜥＋拳兵 | 一个保持射击间距，另一个接近压制 |
| 弩尾蜥＋灯笼灵 | 双远程交叉射击，灯笼增幅与近身震波 |
| 镜盾侍＋灯笼灵 | 正面轻拳弹反，配合队友增幅与远程 |
| 镜盾侍＋弩尾蜥 | 盾侍架势、投镜与蜥蜴后撤射击互补 |
| 双弩尾蜥 | 两个射击方向，收招时按不同方向侧绕 |

所有强阵容都带远程能力，单纯退到近战范围外不会使全队停手。远程攻击具有蓄势、预测瞄准、飞行时间与实体碰撞，发射后不追踪；可以闪避、格挡、贴身打断或利用收招反击，不采用全场瞬间伤害强迫命中。

镜盾侍的青色盾光提示架势弹反窗口：只弹正面低冲击轻拳，重推掌、跳砸、冲击波与绕后可破解。弩尾蜥不可背摔，使用晶矢三射、回身甩尾和独立后撤步；三射准备1.85秒、恢复2.1秒，恢复后半段允许移动转向，但不能攻击或后撤。后撤冷却10秒，移动后恢复1秒。详情见各怪物设计MD。

## 配装、胜利与资源

小怪、精英和首领战前选择本局装备，点击开始战斗才正式进入。正式战斗中不能开装备，练习场不受限制。所有敌人全灭才胜利，组合战斗只发一次二选一战利品；领取后继续下一层，首领胜利结束本局。

生命、装备和血瓶跨层保留。新战斗回满绷住并清除临时效果和敌方弹体。开局选择职业和增益，默认有六瓶血瓶，每瓶回复 50% 生命。普通休息一次补三瓶。死亡结束本局。
