# 远征地图

## 层数与节点

一局共15层，自下向上推进。地图只显示“战斗、精英、休息处、首领”图标和类型，不显示具体怪名、阵容、弱怪或强怪标记；即使已选中过节点，其名字和无障碍标签也不透露成员。

| 层数 | 节点安排 |
| --- | --- |
| 1～3 | 普通战斗，三路选择 |
| 4 | 精英，三路选择 |
| 5 | 休息处，三路汇合 |
| 6 | 普通战斗，重新分三路 |
| 7 | 两个普通战斗，一个可选精英 |
| 8 | 精英，三路选择 |
| 9 | 普通战斗，三路选择 |
| 10 | 休息处，三路汇合 |
| 11 | 普通战斗，重新分三路 |
| 12 | 精英，三路选择 |
| 13 | 两个普通战斗，一个可选精英 |
| 14 | 休息处，三路汇合 |
| 15 | 最终首领samurai |

相邻战斗层保留同路连接，并随机添加同方向的相邻分支，避免交叉乱线；每个节点都有入口与出口。休息处汇合后可重新选择三路。只能进入上一节点连通的下一层，不能跳层或重复刷奖励。

## 弱／强阵容池

“弱怪”和“强怪”是遭遇阵容的分类，不是怪物属性。同名怪物无论位于哪个阵容，生命、攻击力与招式一致，没有隐含增幅。

按本局实际进入的普通战斗计数：前两场使用弱池，从第三场起使用强池。精英与休息处不计入；配装取消不计入，重复打开同一节点不重抽阵容。阵容由地图种子、节点和计数决定，同一种子与同一路线可以复现；连续普通战斗尽量避开同一阵容。

- 弱池：拳兵、刺壳虫、灯笼灵单独出场。
- 强池：镜盾侍单独出场，或下列双怪组合。

| 双怪组合 | 特色 |
| --- | --- |
| 灯笼灵＋刺壳虫 | 增幅与远程灯火掩护低位冲锋、近身环刺 |
| 拳兵＋灯笼灵 | 拳兵近身，灯笼提供增幅、震波与远程追光 |
| 弩尾蜥＋刺壳虫 | 独立后撤、晶矢三射配合正面冲锋，高低判定交错 |
| 弩尾蜥＋拳兵 | 一个保持射击间距，另一个接近压制 |
| 弩尾蜥＋灯笼灵 | 双远程交叉射击，灯笼增幅与近身震波 |
| 镜盾侍＋灯笼灵 | 正面轻拳弹反，配合队友增幅与远程 |
| 镜盾侍＋弩尾蜥 | 盾侍架势、投镜与蜥蜴后撤射击互补 |
| 双弩尾蜥 | 两个射击方向，收招时按不同方向侧绕 |

所有强阵容都带远程能力，单纯退到近战范围外不会使全队停手。远程攻击具有蓄势、预测瞄准、飞行时间与实体碰撞，发射后不追踪；可以闪避、格挡、贴身打断或利用收招反击，不采用全场瞬间伤害强迫命中。

镜盾侍的青色盾光提示架势弹反窗口：只弹正面低冲击轻拳，重推掌、跳砸、冲击波与绕后可破解。弩尾蜥不可背摔，使用晶矢三射、回身甩尾和独立后撤步；三射准备1.85秒、恢复2.1秒，恢复后半段允许移动转向，但不能攻击或后撤。后撤冷却10秒，移动后恢复1秒。详情见各怪物设计MD。

## 配装、胜利与资源

小怪、精英和首领战前选择本局装备，点击开始战斗才正式进入。正式战斗中不能开装备，练习场不受限制。所有敌人全灭才胜利，组合战斗只发一次二选一战利品；领取后继续下一层，首领胜利结束本局。

生命、能量、装备和血瓶跨层保留，新战斗回满绷住并清除临时效果和敌方弹体。初始拥有并装备狂暴，其他槽为空，六瓶血瓶，每瓶回复50%生命；长臂、汲能作为蓝色技能参与掉落。休息处每次补3瓶、上限6瓶，不直接回血。死亡结束本局；事件、商店和读取游戏尚未实现。
