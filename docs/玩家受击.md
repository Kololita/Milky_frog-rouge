# 玩家受击

一级冲击：打断当前动作，抬手后仰，0.65秒后恢复。

二级冲击：身体后仰坐倒，双手在身体两侧支撑。满1秒开始起身阶段，先前倾，再手脚并用缓慢站起，总硬直3秒。自受击满1秒起可以闪避取消剩余起身动作。

三级冲击：向后击飞、仰面躺倒；双手先后撑地、双腿依次支撑站起，总硬直6秒。自受击满3秒起可以闪避取消剩余起身动作。

玩家硬直参数独立配置于battle-values.js的PLAYER_IMPACT，不改变敌人受击参数。受击动作在player-hit-animation.js基于现有骨骼动画生成，不修改模型形状。攻击被中断；硬直结束才处理预输入。狂暴霸体和强制大笑维持原有例外。

起身取消沿用点按Shift的闪避操作、原有方向分类与无敌帧。倒地期间可预输入闪避，到允许时点自动触发；一级冲击无此取消窗口。新受击会重新计时。
