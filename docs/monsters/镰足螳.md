# 镰足螳

- 标识：`scythemoth`
- 类别：精英

共有规则与建模交付规范见[怪物与小怪通则](./怪物通则.md)，本页仅列个体参数与特有机制。

## 外形

### 建模提示词（150字以内）

螳螂精英，高1.95米、足展1.05米，三角头、双复眼、双触角，细胸长0.65米、三节后垂腹长0.65米。仅四条三关节步足及两条三关节镰臂，镰刃长0.6米。对称站姿，两镰展开不交叉，节壳分件、关节留隙。未上色，无场景。

### 详细设计参考（不属于提示词）

高挑的螳螂式精英，三角形头、两只大复眼、两根细触角、细长胸节、后垂的长腹部。明确只有六条主要附肢：四条承重步足与两条前方战斗镰臂。镰刃是前肢末端的弯曲结构，不是手里拿的刀，不增加第二套人形手臂。腹部离地，姿态适合侧切、突刺与飞扑。

### 运动结构与分件

骨架需要胸节根骨、头颈、腹部三节链、左右触角各三节；每条步足至少髋、膝、踝三关节与足爪；每条镰臂至少肩、肘、腕三个旋转关节。节肢外壳各段分件，关节连接处有覆盖球体；不得将镰刃焊到胸部或将四条步足连成一片。

## 行为与应对

左镰高斩：

左镰向上外侧抬起，斜劈胸口高度；右镰保持收势，不会同时造成两刀伤害。准备0.65秒，攻击0.25秒，随后恢复0.32秒并接下一刀。

右镰扫腿：

右镰侧后收回，再低位横切，与前招形成高低变化，可跳过。准备0.72秒，攻击0.26秒，随后恢复0.38秒并接下一刀。

双镰穿刺：

双镰同时后收、多停一拍蓄势，再踏进0.45米向前合拢穿刺；窄扇形中位攻击，适合横向闪避。准备1.15秒，攻击0.28秒，随后恢复1.65秒后再行动。

交镰飞扑：

两镰先向两侧张开，身体前压，再交叉向前飞扑3.6米；用于追击中距离目标，独立于三连镰，扑空留下1.5秒收招。准备0.75秒，攻击0.35秒，随后恢复1.5秒后再行动。

左镰高斩→0.32秒刀间恢复→右镰扫腿→0.38秒刀间恢复→延迟双镰穿刺。三招出手韧性2/2/3，收招耐受1；距离3～7米使用交镰飞扑，准备0.75秒、前进3.6米、韧性3，收招1.5秒；半血及以下两处刀间间隔乘0.75，准备时间不缩短。

## 当前模型与动作

使用 scythemoth_low.glb，骨架29根。四条承重步足、两条战斗镰臂、分段腹部、头颈和双触角独立控制。提供待机、移动、左右切击、双镰突刺、飞扑、受击和死亡，共8段动画。左右镰刃在命中阶段朝身前汇入，双镰动作保持间隔，刃轨迹分别显示。
