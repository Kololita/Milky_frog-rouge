# 弩尾蜥

- 标识：`spitter`
- 类别：小怪

共有规则与建模交付规范见[怪物与小怪通则](./怪物通则.md)，本页仅列个体参数与特有机制。

## 外形

### 建模提示词（150字以内）

四足弩尾蜥，总长2.2米、高1.25米、躯干宽0.65米。长吻与颈0.45米、躯干0.85米、四节长尾0.95米；双眼、两侧颊弩臂、三枚背晶。仅四条三关节步足，各三爪。上下颌可开合，有口腔；尾、晶片分件，关节不粘连。未上色，无场景。

### 详细设计参考（不属于提示词）

四足爬行的蜥蜴式远程怪，短壮躯干、前伸长吻、两侧颊部像弩臂一样展开的晶质结构、背脊三枚晶片与长尾。四条腿都是承重腿，不增加人形手臂。嘴是发射位置，需要真正可张开的上下颌和简单口腔；尾巴是后撤时的平衡器与近身横扫武器。

| 整体 | 从吻端到尾尖约2.20米；含脊晶的最高处1.25米；躯干宽0.65米 |
| 躯干 | 胸腹长0.85米，躯干中心离地0.60米；腹底离地0.35米，骨盆略低于胸 |

| 发射结构 | 左右颊部各一根弩臂状晶质结构，单侧外伸0.22米，向后掠，不能封住口前方；口腔深0.18米、开口至少0.16米 |

### 运动结构与分件

骨架包含胸、腰、骨盆、颈两节、头、独立下颌、尾四至六节、四足各三关节。嘴内需要封闭口腔内壁和口底，不必做逐颗牙齿；上下颌在嘴角连续或分件铰接，不能实心堵口。弩臂与脊晶独立对象随头或胸骨，保留发射口空位。尾根需足够环线供横扫，不将尾与后腿焊接。

## 行为与应对

晶矢三射：

晶簇弩臂张开、吻部蓄光，然后向预判位置发射三颗晶矢，角度间隔0.16弧度，速度10米/秒、射程26米。每颗只接触一次；命中仍遵守受击保护。准备1.85秒，攻击0.25秒，随后恢复2.1秒后再行动，恢复期间只能移动，转向，不能攻击。

回身甩尾：

尾巴向侧后卷起，再回身贴地扫过120度半角范围。低位攻击可跳过。准备0.75秒，攻击0.3秒，随后恢复1.3秒后再行动。

后撤步：

收拢四足、压低头部，连续后撤4米。结束收稳后再独立选择下一动作。瞬间行动，收步0.08秒，随后恢复1秒后再行动。

距离不小于2.5米时用晶矢三射；小于2.5米且后撤可用时，以35%概率后撤，其余情况主动攻击。贴身2.5米内的攻击选择为45%三射、55%尾扫。后撤冷却10秒，冷却中不会选择后撤。后撤与三射独立选择，不自动连放。动作冷却期间不会后撤或再次攻击，晶矢三射恢复后半段允许侧绕、前进与转向，不含隐式后退。受击不会提前清空已开始的动作冷却。决策随机使用可复现种子；不可背摔。

## 当前模型与动作

使用 spitter_low.glb，骨架25根。先统一模型朝向，再绑定四足、分段颈部、下颌与六段尾链。提供待机、移动、晶矢三射、甩尾、后撤、受击和死亡，共7段动画。吐射的蓄光跟随口部；甩尾时将原本高卷的尾巴放低，尾尖在命中时约离地0.38米，对应低位攻击判定。
