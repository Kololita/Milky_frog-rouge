## 外形

### 建模提示词（150字以内）

持太刀的日本武士将领，高2.25米、肩宽1.1米，头身比1:6.4。戴兜盔和面具，身着分片胴甲、大袖、草摺与护胫。双臂双腿、每手五指，太刀长1.65米、双手握柄0.32米，刀独立分件。对称A姿势、张掌，肩肘膝留隙，关节保留环线，未上色，无场景。

### 详细设计参考（不属于提示词）

持太刀的日本武士将领，身穿分片胴甲，佩戴兜盔和面具，以大袖肩甲、草摺裙甲和护胫组成武士轮廓。分段铠甲、宽肩、收腰、稳固双腿和能双手握持的太刀组成明确轮廓。头盔有可见面部开口，胸甲与腹甲分开，肩甲外展但不妨碍过顶举剑。体型强调剑士而非石质巨人，不添加第二把武器、盾牌、翅膀或遮挡手臂的长披风。

### 运动结构与分件

标准五指人形骨架，腰胸至少三段，可双手高举蓄力、竖劈、横扫、刺击及拔剑。剑单独对象，原点在握区中点，本地长轴沿剑柄至剑尖；交付时放角色旁，不嵌入手中。肩甲及裙甲需辅助骨。保持左右骨骼尺寸对称，预留双手共同握剑的空间，不将手指、剑柄或身体焊接。

## 战斗设计

### 基础与阶段

- 生命2200，攻击力6，基础冲击耐受1，可背摔。
- 二阶段生命阈值75%，三阶段阈值40%。达到阈值后，当前刀完成攻击和收招，下一招强制改为引雷转阶段，取消原连段后续刀与等待。名称始终为“武士”。
- 自由走位转向上限100°/s，追击速度1.7m/s，二阶段2.04m/s。
- 常规攻击准备与出手时持续朝向玩家。超慢刀以150°/s平滑追踪，在挥刀前0.22s停止追踪。
- 一阶段普通恢复0.36s；超慢刀插地后原地拔剑1～2s，期间可绕后背摔。二阶段所有收势、刀间恢复、拔剑与连段末尾等待为一阶段的90%，三阶段为75%；两阶段均相对于一阶段计算，不连乘。
- 每套连段保存独立的基础 `recoveryWait`，再应用阶段倍率，不根据刀的快慢、伤害或连段长度临时计算。较长、较重的连段配置较长等待。
- 常规刀间收势0.32s；二连斩前两刀之间0.16s，后续追斩之间0.14s，每刀单独结算一次伤害，不以同一长判定覆盖两刀。

### 引雷转阶段

| 项目 | 设定 |
| --- | --- |
| 阶段流程 | 1→2、2→3各执行一次；若一次重击跨过两个阈值，依次执行两次转阶段，不跳过 |
| 总时长 | 5s，不受阶段收招倍率影响 |
| 动作 | 双手将刀高高举起，持续举刀引雷，最后放回准备姿势 |
| 雷击时刻 | 开始后2.2s，天空雷电准确连接刀尖；该瞬间切换阶段外观 |
| 霸体 | 全程不受冲击硬直、击退、晕眩影响 |
| 背摔 | 全程不可背摔 |
| 伤害减免 | 全程40%，仍可被伤害击杀；结束立刻恢复正常 |
| 周围雷击 | 以武士为中心半径2.6m、覆盖高度0～4m的圆形区域，仅结算一次 |
| 雷击伤害 | 初始动作倍率2，攻击力6时伤害12；基础破绷20，可在开发者设置调整 |
| 雷击控制 | 命中眩晕1s，无击退；不可格挡，可以离开范围或以闪避无敌躲开 |
| 一阶段刀 | 正常刀刃外观，无环绕流光 |
| 二阶段刀 | 整刀黄色环绕，两道流光，角速度2.2rad/s；光芯半径0.006m、柔光半径0.020m |
| 三阶段刀 | 整刀强化黄色环绕，四道流光，角速度4.8rad/s；光芯半径0.011m、柔光半径0.034m |

黄色环绕是独立的螺旋流光层，随刀运动，刀身保留原本材质。三阶段增加环绕数量、粗度和转速。原有突刺、超慢刀的红色不可格挡提示继续保留。转阶段前地面显示雷击范围，雷落下时范围闪亮，雷光快速淡出。

环绕与小光球只覆盖刀刃：刀骨局部轴向0.20～1.64m，避开约0.10m处的刀镡、刀柄与手腕，柔光也留有余量。每道轨道有两颗小光球沿轨道流动，靠近两端时渐隐后循环；二阶段4颗，三阶段8颗，三阶段流动更快。光球使用实例化绘制。

### 诱导与移动招式

| 招式 | 触发 | 动作与时长 | 无敌 | 后续 |
| --- | --- | --- | --- | --- |
| 近身诱攻 | 距离玩家2.7m内，空闲选招时28%概率，冷却8s | 保持待机上身，轻微踱步，最多1.4s；玩家离开3.5m则放弃 | 否 | 观察玩家发起新攻击；未出手则恢复正常选招 |
| 右后闪 | 诱攻期间检测到玩家发起攻击 | 向自身右后45°移动1.7m，0.34s；侧身、双手持刀，刀尖朝向玩家 | 后闪动作全程 | 停顿0.42s后向玩家突刺，冲击力2；突刺与停顿期间均无闪避无敌 |

后闪不主动造成伤害，亦不带破绷、伤害倍率等攻击属性。闪避时所有拳掌、跳砸、气功波、冲击与背摔均不能命中武士；无敌随闪避结束立即结束。玩家可以利用反刺前的停顿再次闪避。

### 连段组成

- 双快刀：左斩 → 独立收势 → 右返。两刀各一次命中。
- 延迟重斩：双手高举重劈 → 短刺追击。
- 慢快慢：斜挑 → 右返 → 压拍重劈。
- 缩距横斩、环扫、钉地重斩：一阶段各自独立成组；二阶段追加一刀，三阶段追加两刀。
- 二连斩：改用双手左右反向斩切，幅度与双快刀同类；先左斩，再右返。二阶段随后再等待0.5s（收势0.14s+准备0.36s），追加三次交替横斩。三阶段最后再蓄势0.5s接当头重劈。
- 二连斩第一刀在刀刃第一次经过身前时结算命中，从首刀开始约 1 秒，对应动画的 `contactPhase=0.35`。右返单独显示预警和结算命中。
- 二连斩以外的常规套路，在二阶段追加一次追斩，三阶段追加两次。后闪反刺始终只反击一次。

### 提示与判定

- 刀保持其材质和阶段特效。白色预警表示可格挡，红色预警表示不可格挡。
- 不可格挡招式直接按未格挡结算，不能普通格挡、完美格挡，也不获得金光；仍可通过闪避无敌或离开范围躲开。
- 其余刀招保持蓝色，可以格挡。攻击前0.15s仍有亮度闪烁提示，但不变红。
- 每个刀段均有独立准备、挥刀、命中和收势。左右双斩不合并为一次长伤害判定，挥空之后不能补中。
- 三维命中范围含独立高度；突刺高度0.65～1.40m，横扫0.10～0.75m，重劈0～2.30m。
- 不再累计完美格挡次数，也没有三次完美格挡强制晕眩。完美格挡的金光与反击奖励保留，冲击按正常耐受结算。
- 基础耐受与出手韧性不叠加。出手期间使用招式韧性，收招、拔剑、等待恢复基础耐受1。

### 模型与动画

- 编辑源：`assets-source/blender/sarumai.blend`；网页：`public/models/enemies/sarumai.glb`；核验副本：`docs/sarumai.glb`。
- 沿用用户校准的52骨骨架、右手持刀及左侧刀鞘；手指骨链方向与同侧小臂夹角不超过60°。
- 常态待机上身不随走位改变，移动仅依次抬腿。普通横斩肘部低于眼线，大臂带小臂挥刀，刀锋迎向切线。
- 20段动画：Idle、Walk、Hurt、Death、CrossLeft、CrossRight、Overhead、BuriedOverhead、Extract、Rising、RisingLeft、RisingRight、ShortThrust、LongThrust、RoundSweep、DoubleLeft、DoubleRight、Backstep、CounterThrust、PhaseShift。
- 招式特效独立保留在 `src/monster-effects.js`，地面预警的颜色由战斗的不可格挡属性决定。

### 验证

`tools/verify_samurai_evade.mjs`覆盖30/60/144FPS的诱攻、后闪无敌、右后方向、反刺停顿与二级冲击、双刀独立命中、预警颜色与格挡规则，以及逐套连段等待参数的实际应用。导出后另检查逐帧旋转、手指角度、刀锋方向和手/刀对躯干的穿模。

`tools/verify_samurai_phases.mjs`验证转阶段排队、5s持续、40%减伤、霸体与背摔保护、雷击范围与1s眩晕、移除弹反计数和各连段90%/75%的等待倍率。`tools/review_samurai_phase_effects.mjs`核验整刀黄色环绕、三阶段数量/粗度/转速增强、雷电连接位置及消散时间。


### 突刺斩更新

原左右快斩删除左斩，保留右返作为第一段，随后间隔0.20秒接不可格挡突刺。快斩动作倍率3.2、破绷24，突刺动作倍率3.8、破绷28、向前1.1m。阶段追加追斩沿用现有规则。仅各类突刺和特慢钉地刀不可格挡，其余刀招可格挡。被背摔时使用放低双手、刀沿地面方向的独立姿态覆盖，避免武器穿过玩家。


### 可格挡标记修正

不可格挡由每段招式明确配置，不再根据动画名称中是否含thrust自动推断。仅“突刺斩·贯刺”“后闪·反身贯刺”和“特慢刀·钉地重斩”不可格挡。使用ShortThrust动画的“快刀·追击”仍可格挡。所有阶段的追加追斩均可格挡，地面预警与伤害结算使用同一标记。


### 缩距横斩与挥刀闪电

原标识thrust的缩距招式修正为“突进·横斩”，使用CrossLeft横砍动画，向前突进2.15m，正前方150度范围，动作倍率4.8、破绷32。所有阶段均可普通格挡或完美格挡；阶段追加刀同样可格挡。真正的突刺仅保留突刺斩第二段和后闪反刺的不可格挡标记，特慢钉地刀仍不可格挡。

二阶段挥刀时，刀刃周围出现3条细金白闪电；三阶段增加为7条，核心粗细翻倍，闪动更新速度从12提高至23次/秒，向外伸展幅度更大。效果随刀刃骨骼移动，只在实际挥刀判定窗口显示，待机、受击、背摔及收势时关闭。现有环绕黄光和光点保留，不新增伤害或攻击范围。
