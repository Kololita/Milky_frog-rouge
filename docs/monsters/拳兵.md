# 拳兵

- 标识：`raider`
- 类别：小怪

共有规则与建模交付规范见[怪物与小怪通则](./怪物通则.md)，本页仅列个体参数与特有机制。

## 外形

### 建模提示词（150字以内）

轻型机械拳兵，高1.55米、肩宽0.76米，头身比1:6，圆头双护目镜、窄腰、球形关节、短拳套。双臂双腿，每手五指，脚长0.32米。对称A姿势、张掌，甲片独立，关节保留环线，腋窝指间不粘连。未上色，无场景。

### 详细设计参考（不属于提示词）

直立双足的轻型机械拳斗兵，圆头、大护目镜、窄腰、外露的球形关节与短筒拳套组成清楚的轮廓。身体略前倾，但交付姿势保持左右对称。整体结实灵活，不做成人类肌肉写实人物，不携带武器、盾牌、披风或背包。

### 运动结构与分件

人形骨架：骨盆—腰—胸—颈—头；左右锁骨、上臂、小臂、手掌；每手四指各三节、拇指两节；左右大腿、小腿、脚、脚趾。护目镜、腰带和拳套外壳为独立刚性件，躯干内部保留可弯曲的连续连接。

## 行为与应对

试探直拳：

左拳收至胸前、肩膀后撤，然后伸直击出；窄扇形中位攻击，可侧闪绕侧反击。准备0.65秒，攻击0.22秒，随后恢复1.1秒后再行动。

转腰摆拳：

右臂向外展开、转腰后横扫身前；宽扇形中高位攻击，比直拳慢、覆盖更宽，不宜仅小幅侧移。准备1秒，攻击0.3秒，随后恢复1.4秒后再行动。

直拳与摆拳交替。
