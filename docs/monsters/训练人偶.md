## 外形

### 建模提示词（150字以内）

关节训练人偶，高1.55米、肩宽0.72米，圆头高0.27米、双圆眼，胶囊胸腹0.48米、骨盆0.2米、腿足0.53米，脚长0.3米。双臂双腿、五指，圆形肩肘膝套独立。对称A姿势、张掌，连接圆滑、关节有环线、指间不粘连。无装备，未上色，无场景。

### 详细设计参考（不属于提示词）

用于练习场的简洁双足关节人偶，圆头、两只圆形观察眼、胶囊形躯干与清楚的肘膝连接组成友善机械轮廓。没有重甲、刀剑、背包或披风，造型应明显区别于拳兵的轻甲战士。可以直拳、走路、被扛起和倒地。

### 部位与比例

| 部位 | 结构与尺寸要求 |
| --- | --- |
| 整体 | 高1.55米，肩宽0.72米，胸厚0.40米 |
| 纵向比例 | 头0.27、颈0.07、胸腹0.48、骨盆0.20、腿足0.53米 |
| 头脸 | 头宽0.30米、深0.28米；两只独立圆形眼部直径0.09米，间距0.13米，无须可动嘴 |
| 胸腹 | 胶囊外形胸宽0.58米，中部不可过度收细；胸、腹、骨盆三段清楚但外表连接圆滑 |
| 上肢 | 每侧臂手合长约0.62米，上下臂比例约1:1，手掌0.14米；五指简化但不能融为连指手套 |
| 下肢 | 大小腿近等长，脚宽0.20米、长0.30米；肘膝有独立圆形关节套，足底平整 |

### 运动结构与分件

使用与拳兵相同的人形骨架层级，手指保留三节与两节拇指。关节套单独对象，躯干和肢体变形网格连续；不在肩窝、胯部或手指之间建立连桥。后背保持平顺，方便背摔时贴附与翻转。
