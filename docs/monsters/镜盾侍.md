# 镜盾侍

- 标识：`mirrorGuard`
- 类别：小怪

共有规则与建模交付规范见[怪物与小怪通则](./怪物通则.md)，本页仅列个体参数与特有机制。

## 外形

### 建模提示词（150字以内）

持镜面光滑盾侍卫，高1.65米、肩宽0.65米，头身比1:6.6，菱形头盔、六棱胸甲、分叉裙甲。左持直径0.74米八角盾，盾材质如镜片，右持0.65米短剑。双臂双腿、每手五指，对称A姿势、张掌，武器盾甲分件，肩肘膝保留环线与空隙。未上色，无场景。

### 详细设计参考（不属于提示词）

修长双足持盾侍卫，六棱躯甲、菱形头盔、分叉短裙甲，一侧前臂持八角镜盾，另一侧手持短刃。造型区别于拳兵的圆润拳套与精英的宽重甲；盾面平整并有浅层边框，适合抬盾弹反和投掷镜片。不要把盾当作胸甲，不做长披风。

### 运动结构与分件

标准五指人形骨架，另有左右裙甲、盾、短刃辅助骨。盾和武器为独立封闭对象并可卸下，不能与手焊接；镜面和边框材质区分开，不建光环。肩部留出盾从腰侧到面前的活动范围；腿间和裙甲间不得有隐藏连面。

## 行为与应对

盾刃突刺：

短刃后收、身体前探，踏进0.85米刺出；可格挡或侧闪。准备0.8秒，攻击0.28秒，随后恢复1.2秒后再行动。

镜面架势：

抬盾迎向玩家，期间获得2的冲击耐受，举盾1s后盾可以进行弹反：检测到玩家在2米内开始符合条件的近战攻击时立即弹反，无需等待攻击命中，弹反窗口时长为0.6秒盾缘发青光，只弹面向方向左右各130度的扇区、冲击不高于1的直接近战。失败则退出举盾状态，弹反成功使轻拳无伤并让非怒气玩家僵直1秒。零前摇，架势持续0.6秒，失败后恢复1秒。弹反成功后盾缘、盾面转为金光，向前推盾的反馈持续0.35秒；只增加动作，不增加伤害或碰撞。如果玩家一直不攻击，则在4s后退出架势。

弹反回斩：

弹反成功专用回斩；短刃侧收，起手立即朝向被弹反的玩家并锁定方向，准备0.1秒后向前踏0.45米横斩，不给玩家再次格挡或闪避的时间，不能直接瞬间命中。准备0.1秒，攻击0.25秒，随后恢复2秒后再行动。

投镜追击：

将镜盾扬起再掷出一颗青色镜片，速度10米/秒、射程26米，向预判位置飞行。避免玩家只退后便永远不受压力。准备1.05秒，攻击0.26秒，随后恢复1.5秒后再行动。

距离大于3米投镜追击，近身交替盾刃与镜面架势。架势冷却3.5秒；弹反成功后0.12秒衔接回斩准备，未命中则有1秒破绽。

## 当前模型与动作

使用 mirrorGuard_low.glb，骨架52根，含双手指骨。短刃、刀柄和盾面按刚性部件绑定，手臂控制握持位置。提供待机、移动、盾刃突刺、镜面架势、弹反外顶反馈、回斩、投镜、受击和死亡，共9段动画。盾面不会随胸甲或手腕蒙皮弯曲；保留银色架势环、成功弹反的金色反馈以及投镜时盾面离手的表现。
