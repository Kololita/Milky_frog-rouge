# 刺壳虫

- 标识：`shellbug`
- 类别：小怪

共有规则与建模交付规范见[怪物与小怪通则](./怪物通则.md)，本页仅列个体参数与特有机制。

## 外形

### 建模提示词（150字以内）

低矮六足甲虫，长1.4米、高0.6米、足展1.7米。椭圆背壳长1.25米、宽0.85米，短头双眼双角，角长0.35米。六足各三关节，背中五短刺、周缘十二枚独立伸缩刺。对称站姿，壳、头、腿段、活动刺分件，不粘连。无翼无尾，未上色，无场景。

### 详细设计参考（不属于提示词）

低矮、宽背、贴地行动的六足甲虫，背部为完整隆起的椭圆壳，前方是独立短头与双角。背壳有可伸缩尖刺，腿从壳下两侧伸出，头和每只足均清楚可见。没有人形双臂、翅膀或长尾。碰撞判定会由游戏单独调高，不要为了判定把模型做成高个。

### 运动结构与分件

主骨根在腹部中心，头颈一节、双角可刚性随头，六条腿各三关节；十二枚周缘刺独立命名spike_L_01至06和spike_R_01至06，轴向指向各自伸出方向，原点在根部。背壳、腹部、头、腿段和活动刺分件；壳要有厚度，伸缩刺不能和背壳共享焊接顶点。

## 行为与应对

顶角冲锋：
在2.7米停步并压低身体蓄势0.85秒，提前0.18秒锁定冲锋方向，随后沿该方向突进3米并顶角攻击。结束后原地恢复1.55秒。 

准备阶段可以打断；横向闪避已锁定的冲锋，然后攻击后摇。低位攻击不能打中已跃过其顶部的角色。

顶角冲锋准备与正式攻击均使用出手韧性1，环身尖刺为1，收招恢复基础耐受0；冲锋对玩家冲击力2、环刺为1。四足类体型不开放背摔。

环身尖刺：

浑身长满尖刺，在1米范围内蓄势1.25秒后，向周围释放环身尖刺攻击。攻击时长0.3秒，结束后原地恢复1.2秒。

距玩家不超过1.25米时使用环身尖刺，否则使用冲锋。环刺为360度攻击，无霸体。冲锋被身体阻挡后仍可用角前范围命中，不会穿过玩家。平时甲壳低矮，环刺准备时周身尖刺逐渐展开。
