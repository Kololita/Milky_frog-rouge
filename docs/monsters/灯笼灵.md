# 灯笼灵

- 标识：`lantern`
- 类别：小怪

共有规则与建模交付规范见[怪物与小怪通则](./怪物通则.md)，本页仅列个体参数与特有机制。

## 外形

### 建模提示词（150字以内）

悬浮灯笼灵，主体高1米、宽深0.7米，四根弧柱连接上下环，顶部檐盖提环，内部独立晶核高0.36米，底部四条长0.42米三节飘带。框内留空，晶核与内罩分离，飘带不交叉，部件独立命名。无脸无四肢，未上色，无光效无场景。

### 详细设计参考（不属于提示词）

没有人类四肢的悬浮灯笼灵体，方圆结合的灯笼外框包围一颗独立悬浮晶核；顶部有小檐盖与提环，底部四条软质飘带。外框构成坚固外轮廓，中间留空，不能用实心球填满。灵动来自晶核悬浮、灯笼倾摆与飘带运动，不增加眼嘴、手脚或翅膀。

### 部位与比例

| 部位 | 结构与尺寸要求 |
| --- | --- |
| 整体 | 外框底到提环顶1.00米，主体最大宽和深各0.70米；游戏另加离地悬浮高度 |
| 框架 | 四根竖向弧柱连接上下环；柱径0.035米，上下环厚0.04米；框内净空宽至少0.50米 |
| 主体 | 灯笼笼身高0.62米，上盖高0.15米，提环高0.13米，下座高0.10米 |
| 晶核 | 多面晶核高0.36米、宽0.28米，中心位于笼身中央；与外框和内罩至少相隔0.03米 |
| 内罩 | 独立薄壁内罩，不与晶核合并；给内外表面正确法线，另有独立材质槽，透光表现后续制作 |
| 飘带 | 底部四角各一条，共四条；每条长0.42米、宽0.07米、有厚度0.008米，三段弯曲区域，静态略张开且彼此不交叉 |

### 运动结构与分件

整体根骨控制漂浮，外框、盖、提环、底座刚性随根；晶核独立骨允许自转与上下位移；四条飘带各三至四骨。晶核、内罩、框架、飘带分别建对象，不烘焙发光效果或光环，不添加地台。飘带根部需明确且连续，不能贴在笼身侧壁。

## 行为与应对

灯焰震波：

接近1.85米后先短暂侧绕，再让光核持续增亮膨胀，1.1秒蓄势后释放360度灯焰震波。地面光环随蓄势扩展，恢复1.65秒。震波只在命中时结算一次，不是持续伤害场。

拉出2.05米范围、跳过低位震波或面向灯笼格挡；也可在准备阶段用冲击打断。

身体脚底高度0.25米，受击体顶高1.2米。震波高度以世界地面0～1米为准，不随悬浮高度上移。

增幅灯笼：

原地咏唱2秒，光核增亮并让所有己方单位在接下来的30秒内获得20%攻击力增幅。结束后原地恢复1秒。

发现玩家后优先原地咏唱；增幅持续期间使用震波，30秒结束后再次咏唱。增幅没有距离限制，包含自己，0.3秒为增幅释放动作，在其70%进度时生效。

增幅使用金色光核与纵向光环，友方受益者脚下出现金色环；震波仍为青色地面环，两个招法的颜色和动作方向不同。

追光灯火：

距离玩家超过2.5米且无需刷新增幅时，停下蓄亮光核，挥动进度70%时发射三枚橙色灯火，速度8.5米/秒、射程26米，三发方向间隔0.12弧度。警戒范围扩大到40米，避免退出近身震波范围后不再出招。

远处蓄势时使用小型橙色竖环，与近身青色地面震波和金色增幅区分。
