# 石槌守卫

- 标识：`stonekeeper`
- 类别：精英

共有规则与建模交付规范见[怪物与小怪通则](./怪物通则.md)，本页仅列个体参数与特有机制。

## 外形

### 建模提示词（150字以内）

岩石守卫，高2.15米、肩宽1.5米，头高0.42米、躯干长1.03米、腿足0.6米。方胸短腿，左手持1.3米柄方头石槌，右手巨大岩拳，另附独立投石。双臂双腿、五指，对称A姿势。岩块、关节、武器分件，不粘连。未上色，无场景。

### 详细设计参考（不属于提示词）

由大块岩石结构组成的双足重型守卫，宽方胸、低矮的块状头、短粗双腿、极宽双肩。轮廓左右不对称：角色自身左手握长柄方头石槌，右手为巨大岩拳，可举起并投掷石块。关节用小型圆滑连接体连接，不依靠悬空碎片支撑身体。

### 运动结构与分件

采用人形层级，石质胸、腹、骨盆、上下臂、大小腿分别为封闭刚性部件；连接球体独立并藏于相邻块体内，不能在弯曲时露出巨大空洞。右手需手掌和五指，左手可握放石槌。槌原点设握柄中央，投石原点居中。腰、肩与肘能支持过顶举槌、低位横扫、右拳砸地及投岩。

## 招式与反制

原有三连段有两套顺序：横槌扫腿 → 裂地重槌 → 岩拳震地，或岩拳震地 → 横槌扫腿 → 裂地重槌。每招都实际出手，横扫与震地沿用均匀的出手节奏。裂地重槌增加插地与拔槌过程，连段中也完整播放，不跳过等待。其他两招出手结束后停0.32秒，再进入下一招的前摇。远距离单独释放涡流水弹。

新增三套连段：
- 沉肩撞山 → 开山挑拳 → 裂地重槌。侧闪让过肩撞，再绕到空拳侧背后，注意拔锤的第二次判定。
- 涌潮震足 → 横槌扫腿。两招都是低位攻击，各自有独立起跳窗口。
- 开山挑拳 → 沉肩撞山 → 涌潮震足。先横移躲开上挑和直线肩撞，看到抬脚再跳。

### 应对窗口

常规近战在挥击开始前0.38秒锁向。裂地重槌举槌过肩，沉髋向前下砸。横向侧闪可绕过狭窄判定区，再找机会背摔。重槌后摇中受到伤害增加35%。

横槌扫腿低位侧收、转体横扫，可以跳过。岩拳震地由右拳落地引发，跳跃或退出2.2米可躲开，后摇中受到伤害增加20%。

未进入近战连段且距离超过4米时凝聚并投出水弹，挥臂前0.55秒锁向，预判提前量0.2秒。横向走动躲避后，可利用2.2秒后摇拉近距离。

## 当前模型绑定与表现

以 stonekeeper_low.glb 为基础，保留高模参考材质。骨架共50根，包含左右锁骨、肘部辅助骨及28根指骨；源模型为闭拳造型，指骨按原有弯曲方向布置。手掌与护腕分开分配权重。石槌为可独立编辑的 `stonekeeper_hammer` 网格，整体跟随 `hammer` 骨骼。握把重建后可沿该骨骼的局部 Y 轴调整握点。

巨槌下砸由双手倒持、槌头朝下蓄势，再沿竖直方向猛插入地，收锤沿左侧抬起。横扫从侧后方蓄势，压低重心后转体扫过身前。岩拳震地先把右拳举到肩外，再屈膝前倾砸到地面。掷岩使用右臂向前挥出。招式特效独立于模型，震地采用灰褐尘环与碎石反馈。

砸拳、掷岩时由肩、肘驱动，右手腕与指骨维持闭拳姿势。持槌手以肩肘带动，手腕保持小臂方向，使用连续的肘部弯曲平面避免翻腕。重槌和横扫在前摇把握点分别向柄尾滑动55厘米、65厘米，以槌头作为攻击前端，收招时复位。裂地重槌从蓄势到下砸、插地均保持双手握柄。落锤后保持1秒，再合力拔出；拔槌开始约0.19秒时产生半径3.2米的小范围伤害，倍率1.5，破绷18，冲击力1，并从插入点向四周迸出分叉地裂、尘土与碎石。连段中重槌收招时长1.7秒，单独或收尾时仍为2.8秒。拔起后副手才松开，武器回到身体侧面。岩拳震地仍为徒手砸地，持槌手将武器留在身体外侧。

## 专属场地

露天八角石台采用低矮的三层台基，台面由错缝石板铺成，中央与边缘设有镶线，外围布置八座石柱。台面留出完整的闪避和绕背空间。正常遇到这个精英时进入石台，也可从设置的开发者模式跳转。
