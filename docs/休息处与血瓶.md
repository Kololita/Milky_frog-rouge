# 休息处与血瓶

奶蛙初始攻击力10。能量转化完成回血10%最大生命，开始时已满能量则15%，中断不回血；这些规则不受血瓶调整影响。

## 血瓶

- 每局初始6瓶，上限6瓶；每瓶一次回复50%当前最大生命，包含装备提供的生命上限。
- 默认R使用，可在键位设置修改，也可点击血瓶按钮。
- 满血、死亡、没有血瓶或不可取消的大笑／背摔过程中不能使用；失败不消耗。
- 普通、精英战后不补充，剩余数量跨战斗保留；新游戏、重新进入练习场或竞技场从6瓶开始。

## 休息处

15层远征中第5、10、14层为休息处，最终第15层为samurai。休息节点进入奶蛙坐在林间凳子上的场景，不经过配装；期间暂停战斗计时。

“休息”每次补充3瓶，上限6瓶，不直接回血；同次停留只能使用一次，重复点击不会继续加瓶。例如0→3、3→6、4→6。继续前进返回地图，可跳过休息。

后续选项通过 `src/rest-site.js` 的 `REST_ACTIONS` 注册，预留其他休息功能。

## 配置

`src/battle-values.js` 的 `POTION_STATS`：capacity=6，healRatio=0.5，restGain=3；开发者模式可调整。使用与补充由 `Battle.usePotion()`、`Battle.refillPotions()` 执行，场景与每次停留的使用限制由 `src/rest-site.js` 管理。

## 血瓶打断规则更新

开始喝药时预扣一瓶，完整2秒后治疗。主动攻击/闪避中断返还这瓶且不治疗；真正受到硬直的攻击中断不返还。无冲击力攻击、异常状态持续伤害不会中断，死亡仍会结束喝药。
