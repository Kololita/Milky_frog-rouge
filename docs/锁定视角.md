# Q锁定敌人

Q在锁定与解除之间切换，目标为当前场地存活的敌人，包括普通傀儡或Boss。奶蛙保持在画面中心，锁定不打断当前动作或连招。镜头距离只能在设置中选择近、中、远，滚轮不再缩放。

锁定期间忽略鼠标的横向转镜头输入，但持续记录鼠标位置，解除后不会由于旧坐标而突然甩镜头。敌人脚下显示金色圆环，头顶显示黄色倒三角。再次Q、敌人死亡、奶蛙倒下、Home重置均会解除；敌人重生后不会自动重新锁定。

20°按水平面定义，顶点位于敌人：比较“敌人→奶蛙”和“敌人→镜头”的两条射线，符合“奶蛙—敌人—玩家/镜头”的夹角。正常容差内保持镜头方位；超过20°即开始回正，目标方位为从奶蛙指向敌人，镜头位于奶蛙远离敌人的一侧。开始回正后，即使角度已回到20°以内，也会继续直到水平夹角归零，避免在阈值附近反复启动。回转按最短弧完成，使用平滑响应并限制最大角速度；角色朝向不参与镜头计算，原有镜头俯角不变。

另有画面边界保护：角度在20°内但目标即将出画、落在镜头后方或位于镜头正下方时，也会开始回正。因为当敌人很远时，三点的几何夹角可能接近0，但敌人仍处在镜头后方，不能仅凭这个角度保证可见。极近距离暂缓选择新的回转方向，避免两者交叉时方向不定。

锁定时，地面自由态下的待机与走路持续面朝敌人；WASD仍按镜头坐标前进、后退或侧移，位移与朝向独立，不触发普通反向调头。松开方向键后的短距离减速保持原移动方向。跑步恢复原本的快速转向与反向调头规则，跳跃保留原移动控制。

所有攻击在实际起手时面向锁定敌人的当前位置，覆盖普通四段、预输入连段、跑攻、跳攻与气功波；忽略方向键与非锁定时后续段的90°修正上限。跳攻的空中前移也朝向敌人。动作开始后不做持续追踪或自动追敌；目标死亡、解除锁定时恢复原方向键攻击规则。格挡保持原来的面向锁定目标行为。

参数集中于 `src/control-tuning.js` 的 `TARGET_LOCK`：容差20°、平滑响应14/秒、最大回转450°/秒、归位误差0.25°、近距离阈值0.25米。镜头实现位于 `src/world-camera.js`，独立位移位于 `src/movement.js`，攻击与朝向接入 `src/main.js`。没有修改Blender模型、GLB和动画。

`tools/verify_target_lock.mjs` 检查19.99°/20°/20.01°边界、最短弧、平滑回正至0、镜头背后目标、死亡及极近距离。`tools/verify_live_target_lock.mjs` 用真实GLB和实际控制循环，在30/60/144 FPS检查锁定切换、鼠标过滤、人物居中、目标可见、走路朝向与死亡/重生。`tools/verify_locked_controls.mjs` 检查八方向平移、跑步恢复朝向、全部攻击类型与预输入时重新读取目标、非锁定回退。以上为离线运行实际控制代码的检查。
