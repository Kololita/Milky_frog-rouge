# 战斗层数与资格

远征每场结束清空能量，生命与剩余血瓶仍继承。下一场从零能量开始。

怪物配置bodyPlan为nonhumanoid时不允许背摔。当前包括刺壳虫、灯笼灵、弩尾蜥、镰足螳；独立配置backThrowable=false也可禁止背摔。

远程弹波完美格挡仍保留金盾与防御档位，但不授予金光、不汇聚金光粒子，也不对远处施法者施加弹反冲击。

远征层数倍率以第一层为1：生命=1+0.03×(层数-1)，攻击力=1+0.01×(层数-1)。最多计算14次增长（生命1.42倍、攻击1.14倍）。不增加攻速、攻击频率、破绷伤害或韧性。竞技场与练习场不增加层数倍率。层数只改变本场怪物实例，不修改基础配置。

竞技场大招装配台默认满级，新游戏仍从初始等级开始。武士阶段机制保留，但名称始终显示武士，血条不再附带状态小字。

伤害类招式默认出手韧性1，部分慢招或重击为2；原有精英重招等明确配置继续保留。具体招式数值见各怪物设计稿。
