# 开发者模式

在开始界面或游戏内打开设置，启用“开发者模式”。参数按用途折叠分组，可以通过中文名称或程序参数名搜索。

- 拖动滑块先修改草稿。点击“应用参数并重置训练场”后生效，并保存在当前浏览器。应用会清除当前战斗进度，重新生成敌人。
- “恢复全部开发参数”只恢复开发参数，不改变键位、分辨率等普通设置。关闭开发面板不会撤销已应用参数。
- 包含奶蛙基础数值、伤害倍率、能量增伤、怒气、格挡档位、闪避无敌帧、移动手感、跑步判定、动画速度、跳跃、背摔、气功波、Boss招式和锁定镜头等32组、350多个数值参数。
- 时间通常为秒；Shift判定使用毫秒，所属分组与标签会注明。格挡及无敌帧按照60帧/秒换算，和渲染帧率无关。角度及角速度使用弧度及弧度/秒。
- 开发面板保留小数以便调试，普通战斗界面仍按原规则显示整数。滑块范围围绕默认值设置，防止极端值导致数值失效。
- 格挡档位、背摔阶段、能量动画阶段、跳跃起落比例需要顺序递增；攻击命中时间不能超出动画。无效组合会提示原因，且整组调整不会生效。

角色网格和GLB内原始关键帧不属于数值调参范围。背摔合成动画会在应用参数时同步重建。镜头距离仍使用普通设置的近、中、远三档。

实现由 `src/tuning-registry.js` 统一持有共享参数，`src/developer-settings.js` 生成滑块及管理独立的本机保存项 `milk-heroes-tuning-v1`。所有入口共用同一组对象，不另外复制战斗规则。修改默认值仍应编辑对应配置模块；开发面板覆盖值仅保存在本机。

只更新网页和共用代码，不更新 release 中的桌面发行文件。
