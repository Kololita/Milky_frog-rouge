# 奶蛙 0.1.0 · Windows x64

材质修正版：修复桌面端安全策略拦截内嵌贴图blob请求、导致身体和手部白模的问题。两个发行文件均已重新生成，版本号仍为0.1.0；请使用新的ZIP完整解压，或重新运行安装包覆盖安装。源模型、贴图内容和骨骼均未修改。新增缺失贴图检查，避免贴图失败后继续显示未染色角色。

开始界面提供练习场和设置；开始新游戏、读取游戏为未开放的不可点击占位。角色加载完成后可进入练习场。Esc打开设置，可返回主菜单。主动大笑按钮和键位已移除，仅保留绷住条归零后的强制大笑。

## 本地运行

- 免安装版：完整解压 `Naiwa-0.1.0-Windows-x64.zip`，双击文件夹里的 `奶蛙.exe`。不要只把exe从文件夹中单独取出。
- 安装版：运行 `Naiwa-0.1.0-Setup-x64.exe`，选择安装位置，安装后从桌面或开始菜单启动“奶蛙”。支持系统应用列表卸载。
- 适用Windows 10/11 64位，需要显卡支持WebGL2。运行时、角色模型和页面资源全部内置，可断网运行，无需Node.js、Blender或开发服务器。
- 设置自动保存在Windows当前用户的应用数据目录，更新或重开后保留；此版本没有游戏存档。
- 此测试版本尚未配置商业代码签名，Windows可能显示发布者未知。

## 默认操作

WASD移动；长按Shift跑步、点按松开Shift闪避；空格跳跃；鼠标左键或J攻击；右键格挡；中键吸收金光；Q锁定；满能量F进怒；Esc设置。可在设置中重新绑定按键。

## 构建与验证

`npm run package:win` 生成Windows安装EXE和免安装ZIP，目录为 `release/0.1.0`。运行时版本固定45.0.0，首次构建下载官方运行时并校验SHA-256，之后复用本地缓存。`npm run desktop` 从源码构建并运行桌面窗口。仅构建产物、桌面启动器及生产依赖进入包内，不包含Blender源文件、历史测试模型或开发服务器。

主菜单、进入/返回练习场及移除主动大笑由 `tools/verify_home.mjs` 验证；绷住条强制大笑由 `tools/verify_break_laugh.mjs` 验证。打包后通过 `--verify-package --report=完整路径` 可验证安装内资源和版本，不创建游戏窗口。
