# 金光蓄力与喝药

金光状态下按住主攻击键或攻击备用键进入蓄力，松开释放气功推掌。每满1秒闪光一次，冲击波伤害增加20%，最高3秒、增加60%，3秒自动释放。短按不满1秒按0级结算。推掌本身伤害不变，冲击波保持独立伤害与原有穿透、同目标1秒命中间隔。蓄力期间不因金光原到期时间丢失已开始的蓄力，取消、受击和菜单操作清理蓄力状态。

喝药持续2秒：右手握瓶，举到嘴前，倾瓶喝下，再放下。通过加载后清理名称的骨骼引用定位右臂与上唇，使用拳击动画的手指握合姿态；瓶口目标跟随嘴部，走动、转身仍可喝药，不能跑步。攻击、闪避或受击会中断，只有喝完才治疗。

绷住在最后一次有效攻击命中后2秒开始恢复，仍每0.1秒结算。

奶蛙闭嘴轮廓用细暗线沿上唇骨骼附着，未更改原身体网格。镜盾侍镜面使用1024×1024反射纹理及4倍多重采样；反射计算前同步整个场景与骨骼矩阵，眩晕、背摔时使用稳定上身姿态。


## 蓄力表现与喝药移动修正

按住攻击立即播放推掌准备段，在0.2秒内收手至蓄势姿势并保持。手前光球随蓄力每满秒脉冲闪烁；释放后从推出段接续，不再重复收手。原环形冲击波改为向前飞行的同款光球，伤害、距离、穿透规则不变。特效仅使用自身发光网格，不使用影响全身的点光源，打断即隐藏。自动眨眼不再中断蓄力。

喝药时允许Idle／Walk／转身步态正常切换，右臂喝药通过骨骼覆盖叠加在步行动画之上；不可跑步。人物移动不再只平移而双脚静止。

## 血瓶打断规则更新

开始喝药时预扣一瓶，完整2秒后治疗。主动攻击/闪避中断返还这瓶且不治疗；真正受到硬直的攻击中断不返还。无冲击力攻击、异常状态持续伤害不会中断，死亡仍会结束喝药。
