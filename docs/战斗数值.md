# 战斗数值

更新：2026-10-28。以下为当前网页端基线，替代旧版伤害与能量描述。时间为秒，距离为场景米；涉及帧的判定统一以60Hz换算为秒，不随渲染帧率变化。运行时伤害保留两位小数，游戏显示向下取整。

## 当前伤害公式与动作倍率

攻击附带近战或远程标签，以及普通、水、火或电属性。全部招式标签与抗性规则见[伤害属性](./伤害属性.md)。

奶蛙初始攻击力为10，运行时为 `battle.player.attackPower`。生命伤害统一为 `攻击力 × 动作倍率 × 能量增伤`，怒气不再提供独立伤害加成。近战与背摔在命中时读取攻击力；冲击波发射时记录伤害，飞行中更换属性不改变该波伤害。

| 动作 | 每击动作倍率 |
| --- | ---: |
| 左直拳 | 1 |
| 跨步右直拳 | 1.2 |
| 左右左三连拳 | 0.8，三次独立命中 |
| 蓄力重推掌 / 金光反击近身推掌 | 4 |
| 气功光球 | 基础 3.6，满蓄 6.48 |
| 跑步双掌 | 1.2 |
| 跳跃下砸（半径1.665米，整段动作时长延长5%） | 3 |
| 背摔坐砸 | 7.5 |

无装备、无能量时：直拳10，右直拳12，三连拳每拳8，推掌40，冲击波30，跑攻12，跳砸30，背摔75。完整四连段总伤害86；金光反击近身与波动分别判定，均命中时合计70。满能量时统一乘1.2。

第一段直拳带向前踏步，前脚先踏出、后脚跟进，前移在出拳命中前完成；空地上完整前移约0.95米，贴近目标时由身体碰撞限制实际前移，可接上跑攻击退后的目标。第二至第四段原有水平前移与对应脚步增加20%，不改变伤害、攻击范围或出拳时间。攻击前移按至多2.5厘米的小步检测碰撞，避免穿过敌人；取消动作后停止前移。

每个攻击命中点对范围内每只敌人分别判定一次；挥空不补判定，取消后不残留近战伤害。冲击波穿透敌人，同一目标1秒内不可再次被波动命中；已经发出的波动在动作取消后仍继续飞行，死亡、重置和战斗结束清除。

## 奶蛙基础与装备

| 属性 | 初始值 |
| --- | ---: |
| 最大生命 | 100 |
| 绷住上限 | 50 |
| 攻击力 | 10 |
| 绷住恢复速度 | 20/秒 |
| 受击无敌 | 0.55秒 |
| 身高 / 身体碰撞半径 | 1.55米 / 0.40米 |
| 血瓶 | 6瓶，每瓶回复50%生命 |

新局先选择职业大招和一项开局增益，装配台初始为空。战利品进入背包，战前手动装备。长臂、汲能均为蓝色技能，可在普通或精英战斗后获得。装备提供攻击力、最大生命、绷住上限、减伤、恢复速度等属性。换装时按比例转换当前生命与绷住，蓝色锁甲为最大生命 +50、绷住上限 -20。

I打开装备面板，正式战斗中禁止打开，练习场允许。进入小怪、精英与boss前先配装；小怪与精英胜利后获得装备二选一。详见《装备与掉落.md》。血瓶默认R使用，满血、死亡、背摔或强制大笑时不可使用；局内跨战斗保留，第5、10、14层休息处每次补3瓶、上限6瓶。

本轮生命提升并非改变招式频率：训练人偶仍为0.7秒准备+2.6秒恢复，其他敌人的蓄势、挥动、恢复、移动速度、基础破绷和冲击耐受不变。拳兵、三种精英和samurai小幅提高攻击力；灯笼灵与刺壳虫保留上一轮手写设计攻击力。

远征敌人的生命与攻击力乘以 `1 + 当前层数 × 2%`。第 1 层为 102%，第 16 层为 132%。基础破绷独立计算。各招完整参数见 `docs/monsters/` 与[武士设计](./monsters/武士.md)。

地图共15层，不标注具体敌人。前两次普通战斗使用弱阵容池，后续使用强阵容池；弱强只区分组合强度，不给怪物添加属性倍率。强池含8种双怪组合与镜盾侍单独出场，均有远程施压手段。每只独立行动、血量、碰撞、受击、背摔与晕眩，全灭才结算一次战利品。灯笼灵咏唱2秒后释放增幅，所有存活友方攻击力+20%，持续30秒，同类增幅不叠乘；不改变基础破绷。

## 绷住与格挡

官方名称为“绷住”，运行时 `battle.player.pose`，旧 `guard` 为兼容访问。每次有效受击扣除 `本招基础破绷 × 格挡档位倍率`；未格挡倍率1。训练人偶基础破绷20，samurai各刀20～60，其他招式以独立怪物文档为准。

| 格挡时间（60Hz基准） | 等级 | 破绷倍率 | 生命伤害 |
| --- | --- | ---: | --- |
| ≤10帧 | 完美 | 0.1，绷住保底1 | 0 |
| >10且≤18帧 | 精准 | 0.25 | 0 |
| >18且≤30帧 | 稳健 | 0.5 | 0 |
| >30且≤60帧 | 普通 | 0.6 | 0 |
| >60帧 | 迟缓 | 0.75 | 本刀生命伤害×30% |

右键格挡保护前方左右各75度；一次至少维持到本次完美窗口结束，提前松手不能缩短。没有其他输入时松手保留4帧宽限，沿用原计时。上次未完美格挡且松手后0.5秒内再按，完美窗口缩为7.5帧，其余档位不变。非完美格挡后8帧无法重新格挡；成功完美格挡没有此空窗，持续按住不会自动刷新窗口。

非完美档位绷住不足时归0，受到攻击者攻击力×1.2的破防伤害，迟缓档再叠加穿透伤害；完美格挡不会破防。生命减伤与破绷独立计算，迟缓穿透比例由 `GUARD_STATS.lateDamageRatio` 配置。

连续2秒未受到有效攻击后，每0.1秒恢复一次绷住，默认每次2点。归0且存活时强制大笑，时长 `1 + 当前绷住上限 / 恢复速度`，默认为3.5秒。期间连续回满，伤害减免+50%，受击不扣绷住、不打断大笑。装备可改变上限与恢复速度。

## 金光、能量、怒气与技能

完美格挡给予5秒金光；再次完美刷新，可用护符延长。反击使用独立 `CounterWave`，近身推掌倍率4、二级冲击，光球基础倍率3.6、一级冲击，速度8米/秒，飞行距离5.425米，半径0.48米。光球最低蓄力时间为0.5秒，点按或提前松手会继续蓄满0.5秒再自动发射。每档提高20%光球基础伤害，满档另加20个百分点，共提高80%。集中缩短每档蓄力时间，最低起放时间仍为0.5秒。发射后的收招与重推掌一致。普通第四段不发光球。

中键转化金光，总动画1.25秒，其中0.38～0.88秒按动画进度连续增加能量，总量33，上限99；中断保留已获得部分，金光与手部残留特效清除。完成时回复10%最大生命，开始时已满能量则15%；中断不回血。允许移动，攻击、闪避、跳跃、格挡、受击等取消。支持动作结束时执行的预输入。

能量增伤 `15% × 能量/99`，满99再额外+5%，不显示状态图标。装备狂暴且满100能量时按3消耗100能量，进入狂暴9秒。期间获得霸体，攻击部分速度×1.2，攻击间隔时长×0.8，每次有效命中回复最大生命3%。角色自身移动、格挡、无敌、金光与怒气计时保持正常。绷住归0的大笑、死亡仍生效。

技能E瞬发，需要先装备。长臂：消耗33能量，30秒内攻击范围+20%，不影响背摔抓取距离。汲能：消耗30%最大生命，当前生命必须严格高于消耗；30秒内每次有效命中获得5能量。两技能持续期内不可重复开启；替换技能取消原效果。图标在角色上方渐入渐出1秒，无动作锁定。

## 冲击、背摔与闪避

冲击等级：一级0.24秒硬直、击退0.12米；二级0.72秒硬直、击退0.85米；三级先在0.2秒内击退1.2米，再晕眩1秒。三连拳为0级；普通前两拳与完美格挡为一级；推掌、跑攻二级；跳砸三级。出招期间以招式出手韧性作为总耐受替代基础值，收招恢复基础耐受；抵消冲击等级但不减少生命伤害。samurai基础耐受1，快刀出手韧性1、重型招式3；完美格挡不再累计次数或触发固定晕眩。武士在75%/40%生命阈值后排队执行5秒引雷转阶段，期间霸体、不可背摔并减伤40%。

背摔：可背摔目标背后100度、中心距离≤1.55米内地面攻击触发，停止双方当前动作。0.95秒跃起，1.25秒最高离地1.05米，1.55秒坐砸75基础伤害，1.85秒后空翻，重新落地即释放操作。目标倒地计时从后空翻开始，总时长 `4×0.8^冲击耐受` 秒，倒地占3/4、起身1/4；倒地无敌，起身可受伤但免疫冲击。起身立刻朝向奶蛙，之后1秒不可再次背摔。

闪避无敌从实际动作开始计算：侧闪14帧、前滚18帧、后空翻24帧。结束连携0.05秒。按下 Shift 时，行走未满 0.2 秒用 0.3 秒翻滚窗口，已满时用 0.2 秒。按住 Shift 并输入移动方向时，匀加速到窗口结束时的跑步速度。窗口内松手触发闪避，超过窗口后松手恢复走路。翻滚按≤0.025米微步检测所有敌人，保留擦边切向位移，不穿身。

## 判定与衔接

三维攻击采用水平扇形／圆形／扫掠胶囊加竖直高度重叠。攻击高度相对攻击者脚底，灯笼震波以世界地面0～1米为准。调试hitbox与实际判定共用上下界，敌红我蓝。

攻击与间隔分开计时：出拳和收拳受攻击速度影响，蓄势、拳间停顿、稳身等受攻击间隔倍率影响。跑攻末尾有0.5秒稳身不可操作（怒气缩至0.4秒）。普通攻击后连携0.05秒，连招窗口0.5秒，从动作结束起算；允许走路，跑步、闪避、格挡、跳跃、受击等中断连招。预输入保留到动作完成时读取。
