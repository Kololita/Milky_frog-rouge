# 开发者模式：获得装备

设置中的开发者模式提供独立“获得装备”按钮，与参数面板、hitbox和跳转并列。打开后显示全部当前装备、技能与大招，各卡片有图标、品质、属性、形状预览及获取按钮。

形状默认随机，预览展示本次会获取的形状，获取后重新随机下一次预览。也可以从下拉框手动指定本类型／品质池中的某种形状。固定占地的技能仍使用自己的固定形状，大招没有占地选择。

点击获取加入当前背包。已有同标识装备可更新形状；折叠和精简记录清除，已有改装升级保留。已装配的装备在新形状仍合法时保留位置，否则回到背包。当前远征也同步拥有记录，后续掉落不再把该装备视为未拥有。

关闭窗口返回设置，不直接进入战斗。
