# 装备升级与商店改装

休息处可在休息、升级装配台、升级一件装备之间三选一。装备升级确认后结束本次休息处。灵巧和精简移至商店，每次确认收费 50 金币。

## 升级

从拥有的装备中选一件，显示升级前后的品质、基础属性与附加被动对比，确认后才生效。本次最多升级一件。

每次品质提升一级，白→绿→蓝→紫→金，金色不能升级。已有基础正面数值每次提升35%后向上取整（百分比按整数百分点），实际战斗与显示使用同一结果；装备名显示升级次数，例如锁甲+1、锁甲+2，无升级不显示+0，负面数值不加重，保留原占地和形状权重，不因新稀有度重新随机占地。已有被动中选择第一个未达单件上限的被动升一级；没有可提升的已有被动时只提升属性与品质，不凭空添加新被动。多个装备的被动仍按全局上限汇总。技能也可升级，提升对应的攻击距离增益、回能速度或护盾量，不提高消耗。

## 灵巧

从滚动装备列表中选装备，可成为拐点的格子发金光。左键选择，右键撤销选择，确认后为这一件装备添加一个拐点；本次总共一个。返回不提交。

候选条件仍为八邻域恰有两个邻格，二者同为对角或相对的正交格，且两侧可划分，至少一次90／180／270度旋转不重叠、不改变格数且能改变占地。

## 精简

可删除的非割点发金光。所选格不得是已有拐点；删除后至少剩一个格子，且剩余形状保持八联通（允许仅对角接触）。左键选择，右键撤销，确认删除一个格子。本次仅一次。

删除记录使用稳定格子身份；从已有拐点两侧归属中移除该格，重新确定较小侧，重新计算候选拐点。现有拐点格保留。后续折叠同样检查形状八联通，不会将装备折成断开的图形。

已装配装备精简后保留剩余格子的棋盘位置，不会意外移动邻接装备或改变数值。品质、升级、增益、拐点与删除历史均持久化，重开装配台或进入下一场战斗仍生效。
