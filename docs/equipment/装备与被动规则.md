# 装备与被动规则

白色默认一项属性；绿色默认两项正面属性；蓝色及以上允许负面属性。装甲、武器、护符的蓝／紫／金装备默认分别分配1／2／3点被动等级；同一被动可获得多点。保留作者明确写明“无”的属性型装备例外。

属性采用设计稿基础数值×类型品质平衡系数×形状权重。按默认格数折算后，同类型相邻品质的属性及被动总价值递增8%，不超过15%；不再使用此前高稀有度陡增的预算。被动等级不乘形状权重，重复被动合并后按各自上限截断。

装备面板“附加被动”独立分组显示名称和等级x/y，悬浮查看当前等级效果。卸下装备或切换装配台重新统计，仅当前已装配装备生效。

减伤按受到伤害的剩余比例乘算（含负减免），总减伤最高75%。血瓶恢复量修正按1+修正乘算，作用于基础50%回血量。血瓶增加只提高容量，不在切换装备时赠送血瓶，休息仍补3瓶。

具体被动见[附加被动](./附加被动.md)，形状与权重见[占地形状池](./占地形状池.md)。


## 每格价值平衡

默认格数白2／绿4／蓝6／紫8／金11。护甲／武器／护符白色每格价值基准为2.5／7.5／4.5，相邻品质乘1.08。属性权重沿用equipment-rolls.js；负属性按50%价值扣除，每点附加被动按2点价值从属性预算扣除。保留装备属性组合、负面代价和被动等级，调整最终属性系数；被动不乘形状权重。技能的主动效果不与护甲、武器、护符直接折算。

奖励需要先选择卡片，再点击确认；只有确认才入包。左侧背包按钮可打开当前装配台，关闭后保留奖励选择，未确认的装备不可提前装配。


## 装备独特性与目录合并

只比较同稀有度、同类型的两件装备：不得共享两个及以上基础属性类型，也不得共享两个及以上附加被动名称。跨品质或跨类型允许相同搭配；数值、正负号和被动等级不同仍视为相同类型。组内冲突项保留一个代表配置。已恢复此前仅因跨品质、跨类型比较而移除的装备；技能及大招单列，集中及其装备、教程演示装备保留。

新增集中装备：静水拳套（蓝）、澄心玉坠（紫）、藏雷战甲（金）。完整属性见对应部位设计稿。已合并条目不再进入掉落池、背包选择或开发者获取列表。
