# 大招设计

共有的品质、掉落、装备和结算规则见[装备与掉落](../装备与掉落.md)。

### 狂暴

无稀有度。

效果：消耗100能量，进入狂暴形态。

标识：`rage`。

- 默认按 3 释放，消耗 100 能量，持续 9 秒。可在远征开局选择。
- 获得霸体，攻击动画速度增加20%，攻击间隔缩短20%，环境速度降低20%。
- 每次命中回复最大生命的5%，不额外增加伤害。
- 眼睛变为纯红色，画面叠加偏红效果，能量条显示剩余持续时间。

数值配置：src/battle-values.js中的RAGE_STATS。


### 拳风

标识：`fistwind`。无稀有度，可在远征开局选择，默认按 3 释放。

瞬间消耗100能量，持续30秒，期间每次拳掌攻击在出拳判定后0.1秒释放劲风，额外造成0.3动作倍率伤害。劲风独立判定，不产生冲击，不触发普通拳掌命中回能，不递归触发自身。跳砸、冲击波和背摔不触发拳风。双方手部环绕稀薄白气，释放时白气随拳掌向前击出。

装配台独立保存，初始中心菱形12格，升级后24格，满级36格。竞技场默认满级。受击不中断持续增益，死亡、战斗结束或更换大招后清除。


### 拳风装配台轮廓更新

采用8×8底板，三级开放16／24／36格；其余格禁用。逐级扩展为带两翼、收窄腰部的风纹轮廓，升级保留已有开放格。
