# 技能设计

下列技能采用固定占地，形状权重为1，不再从技能形状池随机；仍可在休息处改装。最多装配一个技能，使用技能键释放。

### 长臂

品质：蓝。标识：`longarm`。

效果：消耗30能量，30秒内攻击距离+20%。能量不足或已开启时不可重复启动。

占地：
```
...#
.#.#
###.
```

### 汲能

品质：蓝。标识：`drain`。

效果：消耗最大生命30%，持续30秒，每秒恢复3能量，每0.1秒结算0.3。生命必须高于消耗量；不能重复启动。能量获取增益照常作用。改装升级可提高回能速度。

占地：
```
.##.
##.#
..##
```

### 护盾

品质：紫。标识：`shield`。

效果：消耗50能量，获得50护盾，已有不足50护盾时补至50，不叠加。护盾承受减伤结算后的伤害，优先扣除；不计入生命及生命比例，战斗结束清除。

占地：
```
###
###
.#.
```

### 聚能

品质：蓝。标识：`focus`。

效果：消耗35能量，获得一次金光，可用于蓄力气功推掌或转化。持续时间与完美格挡获得的金光相同，受余辉影响。能量不足、已有金光、正在蓄力或无法使用技能时不消耗能量，也不覆盖已有金光。

占地：
```
#.#
.#.
#.#
```
