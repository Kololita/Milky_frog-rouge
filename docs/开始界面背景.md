# 十二生肖开始界面

原始合图保存在 `assets-source/images/zodiac-sheet.png`，按原图像素裁出12张，统一为360×360白底PNG，没有重新绘制造型。文件位于 `public/images/zodiac/`，按鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪编号。

首次打开与每次返回主菜单时随机抽一张；返回时避免连续抽中上一张。右侧展示完整角色，左侧深绿渐变保证菜单可读；窄屏加强遮罩。开始界面完全遮住练习场，并暂停其绘制和模型动画，进入练习场或boss arena后恢复正常绘制。设置保持普通并列菜单项，游戏内仍使用右上角齿轮。

背景列表与随机逻辑为 `src/home-art.js`；`tools/split-zodiac.ps1` 可从原始合图重新裁切。图片随网页构建进入dist，网页与后续桌面构建共用，当前不更新本地发行包。
