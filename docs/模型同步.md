# 模型同步

新角色使用 low 网格，保留造型与面数；握持武器可沿接缝分件，避免槌柄随蒙皮弯曲；骨骼和动作按角色结构分别制作。非 low 高模仅作为材质参考，保存在 `assets-source/blender/reference/`。

1. 保留高模参考，检查 low 朝向、比例和部件。
2. 使用 `tools/bake_enemy_materials.py` 烘焙基础色、法线与 ORM 贴图。
3. 绑定骨骼并制作待机、移动、全部招式、受击与死亡动画；可编辑文件保存到 `assets-source/blender/rigged/`。
4. 导出至 `public/models/enemies/`，运行 `node tools/verify_enemy_models.mjs`，检查权重、变形、接地、动画与多帧率战斗显示，并检查多角度预览。
5. 验证后用 `node tools/publish-enemy-models.mjs 角色ID` 覆盖 `assets-source/blender/角色ID.glb`。

当前灯笼灵使用16根骨骼、7个动画；石槌守卫使用50根骨骼（含双侧锁骨、肘部辅助骨及28根指骨）、8个动画。镜盾侍与武士各使用52根骨骼，分别提供9段与13段动画；镰足螳使用29根骨骼、8段动画，弩尾蜥使用25根骨骼、7段动画。模型文件与动画映射由 `src/enemy-models.js` 注册。此流程不更新桌面发行包。

新增镜盾侍、镰足螳、弩尾蜥和武士使用 `tools/rig_new_roster.py` 制作模型专用骨架与动作。有效原始三角面数、骨骼与动画清单保存在 `assets-source/blender/rigged/角色ID.json`；专项检查为 `node tools/verify_new_roster.mjs`，覆盖整段旋转连续性、命中位置、双手握柄、刚性刀盾、拔刀保持和低位甩尾。
