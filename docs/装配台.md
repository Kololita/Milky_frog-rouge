# 装配台

大招槽下方显示对应的装配台。绿色格可放置，红色格尚未开放。每件装备按自身形状占格，不能重叠，形状中的空洞不占格。当前大招棋盘内的装备生效，装甲、拳套和护符可以同时安装多件，技能最多一件。

点击添加装备选择物品后点击棋盘放置，也可直接拖动。已安装物品可以拖动移动，拖到红色回收站卸下；卸下和清空装配台不会删除背包物品。选中或拖动装备时按R顺时针旋转，Esc取消当前放置。选择期间显示跟随鼠标的半透明形状和“按R旋转”悬浮提示。

每件装备每格重复显示自身图标，底色对应品质。白色通常2～3格、绿色4～5格、蓝色6～7格、紫色8～9格、金色11～13格。同类型同品质共用形状池，奖励生成时抽取并固定形状，最终属性乘相应倍率。详细规则见[占地形状池](./equipment/占地形状池.md)；#代表占格，.代表空洞。

## 大招与升级

狂暴和拳风都可升级三次，依次开放 16、22、28、36 格。狂暴使用 6×6 底板，各级图形中心对称。狂暴 +2 将 +1 的原图与顺时针旋转 90° 后的图形叠加，组成风车。拳风使用 8×8 底板，各级图形左右对称。每次升级保留已开放的格子。

每个大招分别记录等级与装备布局，切换大招只启用其对应棋盘。新大招可通过registerAssemblyBoard注册不同形状和升级掩码，棋盘可以不规则、有空洞，升级不得关闭原开放格。

休息处提供休息、升级装配台两个选项。休息补充3瓶血瓶（上限6）；升级先选择一个拥有且未满级的大招。执行一项后结束本次休息处并返回地图；取消升级选择不消耗机会。新游戏重置所有装配台等级与配装。

## 翻转与吸附（0.2.4）

拿起装备后，R旋转、F水平镜像翻转；F以画面方向为准，保留拐点身份及两侧成员。翻转、折叠和精简共同写入形状历史，重开界面和进入战斗后保留。装备需要先拿起，不能直接翻转已安装装备。

每2秒检查手持装备附近0.5格内的合法原点，保持当前旋转、翻转和折叠形状，找到时将界面内的自定义鼠标和图形一起吸到对应位置。不会自动安装；点击/松开拖动仍会校验边界、占用和单技能限制。
