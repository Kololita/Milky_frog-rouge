# 特殊攻击与快速衔接

J 和鼠标左键共用攻击入口。跑步时触发 RunAttack：双掌前推并跨步，连招按已打完第二段处理，下一次攻击为第三段三连拳。跳跃时触发 AirAttack：读取触发瞬间的实际离地高度，在 0.5 秒内持续上升固定 0.35 米、向起跳方向前移并缓缓举拳蓄势，然后快速伸腿下砸；落地停留 0.2 秒，再收腿、原地后空翻起身，直接恢复自由态。后空翻翻转段恢复原生约 0.78 秒的节奏，比之前约 0.52 秒更从容。跳跃攻击结束清空原连招阶段，下一次攻击从第一拳开始。

两种特殊攻击均支持提前输入下一条攻击、格挡或闪避，不会重复触发自身或再次加高。跑步攻击收招后连携0.05秒，续招窗口另计0.5秒。跳跃攻击必须完整播完原地后空翻，不能通过预输入跳过恢复动作；结束时没有额外连携等待，已按住的方向键立即恢复移动。如果额外预输入了攻击，则在完整恢复后从第一拳开始执行。

跑攻目前以约 34° 的躯干前倾配合前跨右脚、双掌快速推出。原生根骨骼前移由约 0.076 增加到 0.284 模型单位，网页实际推进约 0.40 场景单位，约为原来的 3.7 倍；前推不在收招时撤回。末帧保留 Attack2 的局部姿态，仅增加持续的整体位移，接三连拳的规则与播放总时长保持原样。验证：`tools/verify_push_contact.mjs`、`tools/verify_special_attacks.mjs`、`tools/verify_mobility_links.mjs`。

## 运行时攻击节奏

原有四段 Blender 动作及原始 GLB 关键帧保持原样。网页用更快的播放速度与收招点缩短后摇；存在预输入时，到有效衔接点即接下一动作，避免先恢复待机再出拳。第四段的蓄力仍约 0.35 秒。

| 动作 | 无预输入时约耗时 | 已预输入时最早约可衔接 |
| --- | --- | --- |
| 左直拳 | 0.49 秒 | 0.30 秒 |
| 右直拳 | 0.60 秒 | 0.41 秒 |
| 左右左三连拳 | 0.72 秒 | 0.58 秒 |
| 重推掌 | 0.92 秒 | 0.92 秒 |
| 跑步双掌推击 | 0.54 秒 | 0.36 秒 |
| 跳跃蓄势砸地、后空翻起身 | 约 2.11–2.24 秒（触发高度 0–0.8 米），含 0.5 秒持续蓄势、0.2 秒落地停留 | 必须完整播完后空翻，直接恢复自由态 |

前滚翻、后空翻、侧闪的距离及方向分类保持原规则。后空翻落地面向撤退方向的反面，与完整后空翻的朝向一致；该朝向写回人物控制状态。前滚翻收尾增加 0.05 秒，结束后的连携窗口现均为0.05秒。不超过0.7秒的格挡和左右侧闪会保留攻击段数、暂停连段过期计时，结束后重新提供 1 秒续段窗口。例：第一拳 → 侧闪 → 攻击，接右直拳；第二拳 → 格挡保持 → 攻击，接三连拳。

下砸首次接地触发衰减镜头震动及地面扩散环，不影响输入、朝向和蓄势／起身时序。反馈参数在 `src/impact-feedback.js`。

## 文件与验证

新增动作保存在 `assets-source/blender/frog.blend` 和 `output/frog.glb`，运行时模型为 `public/models/characters/frog.glb`，共 27 段动作、149 根骨骼。`tools/frog_special_attacks.py` 制作两段新 FK 动作，`-- --special-attacks-only --no-preview` 可单独重建；生成时保留原有网格、蒙皮、骨架及 25 段动作。

`src/combat.js` 管理节奏、提前衔接点和跳跃砸地轨迹。跳跃攻击的竖直轨迹需要读取当次游戏高度，因此 GLB 提供姿势和原地后空翻，网页负责二次跃起、快速下砸和后空翻腾空的高度。蓄势时沿攻击触发瞬间的方向前移 0.18–0.6 场景单位，距离随起跳速度变化；下砸、落地停留和后空翻阶段保持落点不变。`src/floor-probe.js` 缓存全身实际蒙皮顶点测量最低点，倒立时也检查头部，避免后空翻中头部穿地。AirAttack 保留原生水平补偿，不再从骨骼中提取额外位移。

`tools/verify_special_attacks.mjs` 验证连招阶段、固定额外高度、0.5 秒连续蓄势、0.2 秒落地停留、真实 GLB 的逐渐举拳与伸腿、后空翻角度和落地接地。`tools/verify_air_charge_source.py` 确认本次仅替换 AirAttack，保留原有模型、蒙皮及其他 26 段动作。`tools/verify_live_controls.mjs` 运行实际 main.js 的事件处理和帧循环，验证蓄势持续上升前移、起身原地翻转、方向键从连携态一直按到自由态、R 取消动作保留移动键，以及预输入攻击从第一拳开始。覆盖 30 / 60 / 144 FPS。报告位于 `output/animations/`；最新预览为 `AirAttack.gif` 和 `docs/air-charge-review.jpg`。
