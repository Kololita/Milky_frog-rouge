# 网页运行时代码与检查

游戏规则与Three.js显示共用同一套源码，桌面版在明确要求重新打包时复用网页构建。

- `battle-values.js`：角色初始数值、动作倍率、冲击等级、防御及增益配置。
- `combat-damage.js`：角色攻击力乘动作倍率的公共伤害计算。
- `battle.js`：命中、统一敌人受伤/死亡/怒气回血、防御、资源和战斗时钟。
- `training-dummy.js` / `samurai.js`：普通人偶与Boss独立AI。
- `enemy-steering.js`：敌人限速、平滑加减速转身。
- `parry-recoil.js`：完美格挡右肘外顶的纯视觉叠加，不参与战斗判定。
- `actor-collision.js`：微步圆形碰撞与沿身体边缘滑动。
- `back-throw.js` / `throw-grip.js`：双人背摔时间线、动作组合与手部接触。
- `movement.js` / `combat.js` / `character-state.js`：移动、动作计时和自由/连携状态。
- `main.js`：连接输入、游戏规则、动画与场景绘制。

清理了已删除状态栏与动作按钮的文字、逐帧更新和样式，移除了已取消的滚轮缩放函数及参数、旧三层能量配置，以及不再使用的标记和导入。普通攻击、冲击波和背摔复用一次敌人受伤结算，统一处理增益、冲击、回血和死亡；攻击根位移与Boss姿势插值减少逐帧临时对象。

当前规则的统一检查入口为 `npm run verify`，覆盖19组逻辑检查；网页构建为 `npm run build`。检查包括实时攻击力变化、动作倍率、波动伤害快照、背摔、怒气回血、格挡、人偶间隔移动、敌人转身与招式追踪、外顶反馈不改变战斗状态、空中坐砸、起身保护、不同帧率人偶周期、翻滚擦边、连招、锁定、能量、UI与设置。不会运行桌面安装包构建。
