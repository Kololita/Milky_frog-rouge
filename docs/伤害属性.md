# 伤害属性

每次伤害同时有攻击类型和元素属性。攻击类型是近战或远程，元素属性是普通、水、火或电。

## 抗性

每个角色有物理、水、火、电、近战、远程六项抗性，以百分比表示。每段伤害分别乘以对应元素和攻击类型的剩余伤害比例。例如 30% 水抗与 10% 远程抗使水系远程伤害保留 63%。同一项玩家抗性的职业、装备与临时增益乘算，上限为 99%。两项 20% 火抗合计为 36%。物理抗性只对应普通属性伤害，负值会提高受到的普通伤害。抗性同时影响护盾吸收和生命损失。绷住伤害和冲击力独立结算。

「元素之怒」每级增加 10% 水、火、电伤害，上限五级。水、火、电系专职各上限一级，将普通属性攻击的 50% 转为对应属性。两项专职各转 50%，三项专职平分全部普通伤害。转换后的伤害享受元素增益，各属性独立结算抗性后合计。同一次命中只触发一次命中效果。拳风反弹沿用弹体原属性。

单位在雨中受到的电伤增加与火伤减免分别与抗性相乘。
