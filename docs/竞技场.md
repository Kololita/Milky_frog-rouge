# 竞技场

开始界面点击“竞技场”，可选择samurai、8种双怪组合、5种单怪及3种精英。列表按“小怪组合”“单只小怪”“精英”分组，窗口内可滚动，小屏幕使用单列。

所有小怪组合直接从 `src/encounters.js` 的注册阵容读取，与远征使用相同数值和机制。当前包括灯笼灵＋刺壳虫、拳兵＋灯笼灵、弩尾蜥＋刺壳虫、弩尾蜥＋拳兵、弩尾蜥＋灯笼灵、镜盾侍＋灯笼灵、镜盾侍＋弩尾蜥、双弩尾蜥；单怪为拳兵、刺壳虫、灯笼灵、弩尾蜥、镜盾侍。

点击阵容后先进入配装，拥有全部测试装备，点击“开始战斗”才进入。独立训练不消耗远征进度，生命与绷住回满、血瓶6瓶。正式战斗不能打开装备面板；可以用Home重置当前阵容，或通过设置返回主菜单。

模型未加载完成时挑战按钮禁用。界面：`src/arena-menu.js`；共享遭遇注册：`src/encounters.js`；数值：`src/monster-catalog.js`。

精英可单独挑战灰烬司炉官、石槌守卫、镰足螳；与远征精英共用机制及数值。详见各自设计文档。
