# 新手教程

主菜单进入教程目录，三个按钮分别进入独立流程。使用当前自定义键位，不影响远征进度。Esc返回教程目录，完成后Enter返回目录。

## 基础操作与机制

11步：移动、鼠标视角、疾跑、锁定、生命/绷住/能量、跳跃、闪避、格挡、完美格挡、转化金光、血瓶。

格挡两步人偶正常出拳，并保留攻击预警；其余步骤停止进攻。转化金光时提供练习金光，血瓶步骤提供缺血与血瓶，保留最低生命保护。

## 装备与装配

9步：选择大招、放置装备、R旋转、T折叠、Y切换拐点、卸下、安装技能、释放技能、释放大招。

自动打开狂暴+2装配台，6×6全部开放，提供护甲、守势拳套、护符和四个技能。守势拳套固定为双拐点形状。教学提示放在装配弹窗内，暂停战斗时仍能推进。技能释放步骤自动关闭装配台，并为技能与大招准备能量。

介绍大招决定装配台形状与开放范围，并说明狂暴、拳风的效果。拿起装备时，鼠标锚点为当前拐点，无拐点时为占地格中心的平均位置。

## 招式大全

18项：四段普通攻击、跑攻、三种跳跃、跳砸、金光蓄力光球、背摔、前滚、后空翻、侧闪、长臂、汲能、护盾、聚能、狂暴、拳风。N下一招、P上一招。

按实际命中、动作和技能事件判断完成。切换练习会重置位置、临时效果和装配；技能练习自动装上对应技能，大招练习自动选择对应大招并充满能量。背摔练习将人偶背面朝向玩家，后空翻/侧闪练习保留朝向，避免自由态方向跟随影响动作分类。

## 跑攻衔接

跑攻出手结束进入0.5秒后摇，期间可以立即走动或翻滚，只锁定攻击。提前预输入的翻滚在后摇开始时执行，不等后摇全部结束。后摇按战斗时间计时，切换走路动画或翻滚不会清除尚未到期的攻击限制。

## 教学流程修正

装配教学从实际选择大招开始，两种演示大招均提供满级装配台。技能试放自动关闭装配界面，准备足量能量与生命，清除残留金光、护盾、技能效果及动作锁；保留刚装上的技能。操作计数使用独立快照，折叠、切换拐点与选择大招能正确识别。

基础教程省略着火、休息处等细节，装配教程省略品质/改装长段说明。血瓶主动攻击或闪避打断会返还瓶数，无冲击力攻击及持续异常伤害不打断。
