# 游戏设置

界面设置现为“显示UI程度”：无（隐藏游戏界面，保留设置入口）、简略（默认，只保留状态条及目标上的伤害数字）、详细（额外显示生命、防御、能量、目标生命数值及战斗说明）。战斗界面的数值向下取整，装备属性和效果的显示值四舍五入到最近的0.5倍数，计算保留原有精度。视野角度固定48度，移除角度滑杆，镜头距离只提供近、中、远三档。锁定时目标头顶显示黄色倒三角，跟随目标位置，解除锁定或目标死亡时隐藏。

游戏中点击右上齿轮图标或按Esc打开，练习场暂停。点击返回或再按Esc恢复。设置自动保存在当前浏览器本机，提供恢复默认按钮。开始界面的“设置”作为普通菜单项，与练习场等选项并列。设置内不提供调试场地快捷入口，Boss场地从主菜单并列的“boss arena”进入。

- 渲染分辨率：自动原生、1920×1080、1600×900、1280×720、960×540。按当前窗口比例适配目标分辨率边界，不拉伸画面；调整的是实际渲染像素，界面保持清晰。
- 帧率上限：跟随显示器、30、60、90、120、144 FPS。默认跟随显示器。限制更新与绘制频率，移动与战斗使用实际经过时间。
- 垂直同步：由浏览器/显示器控制。WebGL没有强制关闭显示同步的网页接口，因此菜单显示实际限制，不提供无效开关。
- 镜头距离：近3.5米、中5.5米、远8米，平滑切换。鼠标滚轮不再调整距离。
- 鼠标灵敏度0.25–2.5倍、水平反转、冲击镜头晃动；视野角度固定。
- 动态阴影、亮度、战斗界面显示、切换全屏。
- 键位：点击对应按钮，再输入键盘或鼠标按键；冲突时提示，Esc取消录入。移动、跑步/闪避、跳跃、攻击/备用攻击、格挡、吸收、锁定、切形态和测试动作均可调整。

`tools/verify_settings.mjs` 检查菜单开关、保存恢复、重映射后的真实角色移动和格挡、滚轮事件移除，以及30 FPS限制下模拟速度正常。原有格挡及闪避回归与生产构建通过。
