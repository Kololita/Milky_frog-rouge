# 能量与拳风

长臂消耗30；汲能保留30%最大生命代价，30秒持续回能，每0.1秒基础增加0.3，不再按命中回能。

耐冲满级2，一级免疫一级冲击硬直，二级免疫一、二级冲击硬直；不削减伤害或破绷。非免疫冲击保留完整等级和硬直，不做减法。
