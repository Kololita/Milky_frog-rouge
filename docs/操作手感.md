# 操作手感参数

当前手感参数集中在 `src/control-tuning.js`。这些参数管理运行时控制与动作混合。新增跑步攻击、跳跃攻击及攻击节奏见 [特殊攻击与衔接](特殊攻击与衔接.md)。

| 项目 | 当前设置与效果 |
| --- | --- |
| 基础速度 | 行走 1.2、跑步 2.8，保留与原步幅的配合 |
| 起步 | 响应系数 18，约 0.13 秒到达九成速度 |
| 松键停车 | 响应系数 26，低于 0.05 后停止；行走约 0.13 秒、跑步约 0.16 秒停稳 |
| 停车滑行 | 行走约 0.045、跑步约 0.106 场景单位，约为原来的一半 |
| 跑转走减速 | 响应系数 20；松开 Shift 后依据实际速度切换，避免腿部突然减速 |
| 转向 | 上限 1080°/秒，接近目标时收缓，误差小于 0.5° 时吸附到目标；90° 约 0.13 秒 |
| 反向调头 | 新方向偏转至少 150°，走路 0.42 秒、跑步 0.46 秒；换步后直接接续移动 |
| 动画混合 | 起步 100 ms、停车 120 ms、走跑切换 130 ms、战斗和调头衔接 55 ms、闪避 35 ms、跳跃 45 ms |
| 迈步同步 | Walk / Run 切换保留归一化相位，保留同侧脚的迈步进度；播放速度随实际移动速度调节 |
| 连续动作切换 | 从当前实际混合权重继续过渡，权重和保持为 1，避免反复切换时回弹到旧姿势 |
| 鼠标转镜头 | 每像素 0.004 弧度，灵敏度降低 20%；停止滑动后不继续旋转 |
| 滚轮 | 灵敏度从 0.0018 降为 0.0012，带响应系数 20 的柔和缩放；保留 2.5–30 的范围 |

移动和刹车距离采用指数速度曲线的解析积分；调头结束会消费本帧剩余时间，避免不同帧率下多停一帧。角色位置仍保持画面居中，镜头平移同步角色，只有滚轮距离做缓动。

保留的规则：Shift 在 180 ms 内松开才闪避；攻击收招后连携0.05秒，另有0.5秒续招窗口，所有闪避结束后连携0.05秒，格挡结束后连携0.5秒；预输入保留至当前动作完成；首段攻击直接朝向目标，后续最多修正 90°；闪避距离和方向分类、自动眨眼 10–13 秒均保持原样。

验证记录：`output/animations/control-feel-verification.json`、`locomotion-turn-verification.json`。测试覆盖 30 / 60 / 144 FPS、起步反向误判、停车距离、换步接续、真实 GLB 的走跑相位与连续动作权重，以及镜头缩放边界和停止后不漂移。战斗、预输入、跳跃、连携态和面部表面的检查也已通过。

攻击的衔接阈值、播放速度与空中砸地轨迹集中在 `src/combat.js`；具体数值见 [特殊攻击与衔接](特殊攻击与衔接.md)。

跳跃攻击用 0.5 秒连续跃起、向起跳方向前移并缓缓举拳蓄势，再快速下砸；落地停留 0.2 秒，随后原地后空翻起身，翻转段约 0.78 秒，完成后立即进入自由态。前移距离随起跳速度在 0.18–0.6 场景单位之间变化，下砸和起身不继续前移。移动解锁只以自由/连携状态为准，过期的动画句柄会被清理；同一帧完成恢复即可读取持续按住的方向键。R 取消动作不清空移动键，Home 和窗口失焦仍清空输入。

## 跳跃与闪避衔接

曾经出现卡顿的两个原因：原地跳的原生准备段为 0.33 秒，走跳为 0.175 秒、跑跳为 0.14 秒；此外，空格未进入预输入队列，跳跃期间的闪避也被直接忽略。现在空格、攻击、格挡、闪避共用单条预输入，后输入覆盖前输入。攻击或翻滚中按空格可直接接跳跃，跳跃中短按 Shift 会在落地后接闪避；跳跃中攻击仍立即转为空中砸地。连续跳跃会重新启动同一个动作，不需要再次松开方向键。R、Home、失焦清空预输入。

`src/combat.js` 的 `MOBILITY_TIMING` 和 `mobilityTime` 只压缩普通跳跃、闪避的准备与落地收尾，按实际经过时间映射至原生 GLB 动画，保留全部姿势、完整翻转、跳跃高度和闪避距离。空中砸地独立使用 `AirSlam`，其 0.5 秒蓄势、0.2 秒落地停留和放慢的起身后空翻不受影响。

| 动作 | 当前准备段 | 当前落地收尾 | 当前网页总时长 |
| --- | --- | --- | --- |
| 原地跳 | 0.065 秒 | 0.12 秒 | 约 1.025 秒 |
| 走跳 | 0.045 秒 | 0.10 秒 | 约 0.945 秒 |
| 跑跳 | 0.045 秒 | 0.10 秒 | 约 0.785 秒 |
| 前滚翻 | 0.035 秒 | 0.125 秒 | 约 0.813 秒 |
| 后空翻闪避 | 0.045 秒 | 0.11 秒 | 约 0.847 秒 |
| 侧闪 | 0.025 秒 | 0.08 秒 | 约 0.659 秒 |

从按键到实际明显离地（最低点高于 0.02 米）的测量：原地跳由约 0.35–0.37 秒缩短到 0.09–0.10 秒，走跳、跑跳缩短到约 0.06–0.07 秒。Shift 闪避仍在短按松开时触发，长按跑步不会触发闪避。验证：`node tools/verify_mobility_links.mjs`，覆盖 30 / 60 / 144 FPS、各方向闪避距离、落地接续、相同跳跃动作重播、连携窗口跳跃和输入保留；对比记录为 `output/animations/mobility-before.json` 和 `mobility-link-verification.json`。

前滚翻的落地收尾在上次压缩基础上增加 0.05 秒，连续翻滚之间也会经过这段收尾。不超过0.7秒的格挡和左右侧闪暂停攻击连段的过期计时，结束时重新给予 1 秒续段窗口；继续攻击从下一段开始。普通前滚翻、后空翻、跳跃等仍按原规则清空连段。后空翻落地朝向为撤退方向的反面，和原生后空翻姿势一致。

下砸的落地反馈由 `src/impact-feedback.js` 管理，真实接地时仅触发一次。镜头位置与瞄准点同时平移，约 0.24 秒内衰减回零，不改写鼠标方位和缩放距离；地面环在固定落点扩散约 0.45 秒。R、Home 取消反馈。普通跳跃的左右手腕在腾空段对齐到原右手的高度。

格挡更新（2026-10-21）：右键按下举起、松开结束；按住超过0.7秒立即清空攻击连招，下一次攻击从第一段开始。

当前规则更新（2026-10-21）：攻击结束后0.05秒恢复自由态，0.5秒内可续招，期间仅待机/走路保留连招；跑步、格挡、闪避及其他动作立即断连，取代早期短格挡和侧闪保连规则。闪避仍由Shift点按松开触发，无敌改为动作第0帧立即开始，侧闪8帧、前滚12帧、后空翻18帧。完整规则以 [战斗数值](战斗数值.md) 为准。
