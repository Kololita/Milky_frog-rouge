# 地图事件

15层地图中，自第三层起的部分非精英、非休息、非首领分支改为问号事件。前两层仍为普通战斗。进入事件直接打开选择界面，不进入配装和战斗；选择结算后点“继续前进”通过当前层。

### 林间清泉

饮泉恢复30%最大生命；或灌装补充1瓶血瓶，不超过携带上限。

### 受伤的行商

失去20%最大生命换绿色装备；或消耗1瓶血瓶换蓝色装备；也可以直接离开。

### 荆棘中的旧箱

免费取得白色装备；或失去25%最大生命，取得蓝色装备。

### 旅途石龛

消耗1瓶血瓶换蓝色装备；或静坐恢复15%最大生命。

生命代价不能导致死亡；血瓶不足或装备奖励池耗尽时禁用对应选择。所有生命数值向下取整。装备从对应品质、未拥有且可掉落的物品中抽取，带随机形状，收入本局背包，不自动装配。结果由节点种子确定，重复检查不会重抽。每次事件只结算一次。

实现：`src/run-events.js`维护事件定义、代价与奖励结算、事件界面；`src/run-map.js`负责节点与进度；奖励通过网页与桌面共用的装备及生命接口生效。普通网页更新不修改桌面发行包。
